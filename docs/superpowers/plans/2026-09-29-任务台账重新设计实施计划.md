# 任务台账重新设计实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 用户已确认在当前会话顺序实施，完成后独立审查。

**Goal:** 使用完整材料、用户要求和所选表头生成可追溯的任务台账，并提供简洁预览与独立模型设置。

**Architecture:** 保留 `excel.material_ledger`、现有资料副本、后台任务及确认写入流程。复用 Word 全文读取，补充 CSV/XLSX 读取；后端根据接入能力组装文本或多模态请求。前端在现有控制器内增加列勾选和出处下钻，不重构其他任务。

**Tech Stack:** Python 3.8、FastAPI/Pydantic、WPS JS/HTML、Node.js/Vite/Vitest；不新增依赖。

**Spec:** [任务台账重新设计](../../specs/任务台账重新设计.md)，用户已于 2026-09-29 确认。

## 全局约束

- 沿用当前工作目录，不创建分支或 worktree；不改动运行态配置及用户已有未提交文件。
- 不新增依赖，确需依赖时另行说明并取得确认。
- 全文不自动摘要、筛选或截断；不支持多模态时只处理文本及表格，并显示未处理图片范围。
- 不执行公式、宏、附件或外链；保留现有写入与资料安全措施。
- 新逻辑先用失败测试复现需求再实现；图标等低影响静态改动以视觉及资产校验验证。
- 所有任务仅提交本任务明确修改的文件；不得使用全目录暂存，不提交 `config/adapter.json`、`run/`、审查临时文件或已有用户改动。
- 本计划不包含安装包发布。真实 WPS、真实模型和目标机测试未运行时必须明确记录。

## 审查重点

1. 旧资料仅有片段、原文件已丢失：必须要求重新导入，不能声称全文输入。归任务 1。
2. 模型请求遇到鉴权失败或超时：不能误判为不支持图片而静默重试。归任务 2。
3. XLSX 隐藏内容及没有缓存值的公式：内容不可丢失，未计算值不能当成空白事实。归任务 1。
4. 用户切换工作簿后旧请求返回：不得污染当前预览或允许旧结果写入。归任务 3。
5. 模型输出长文本、伪 HTML 和公式形态字符串：预览不得执行 HTML，复制及写入不得绕过既有公式注入防护。归任务 3。

## 文件与接口分工

以下新接口为本计划的实施约定，不表示当前代码已存在。共享 DOC 转换和模型能力字段优先沿用现有协议；实施发现不兼容时先修订本计划对应接口，不另造同义协议。

- 新增 `adapter_service/app/services/excel/material_document.py`：`extract_document(content: bytes, file_name: str) -> dict`，返回与 Word 全文读取相同的 `blocks`、`images`、`unreadObjects`，Word 格式委托已有读取器；CSV/XLSX 增加来源行列信息。
- 修改 `excel/material_store.py`：保留 `import_material(session_id, doc_identity, file_name, content_base64) -> dict`、更新及复用入口；新增 `get_full_document(session_id: str, material_id: str) -> dict`，返回完整读取结果；缺少原件或完整数据时明确报错。图片字节仅在后端内部使用，不进入普通 JSON 目录响应。
- 修改 `excel/material_ledger.py`：保留提交/轮询接口与表头字符串数组；在任务快照固定全文及图片模式，结果增加 `inputCoverage`，包含 `mode`（`text` 或 `multimodal`）、`omittedImageCount`、`warnings`。原有行、出处、缺项和重复结果结构保持兼容。
- 修改 `provider_client.py` 及必要的任务配置允许列表：沿用既有参数与图片通道，允许 `excel.material_ledger` 按能力发送图片，不改变 Word 策略。
- 修改 Excel 插件 `material-ledger.js`：增加 `setHeaderSelected(index, selected)`；保留现有 `setHeaders`、`readSelectionHeaders`、`generate`、`openSourceDrawer`、`closeSourceDrawer`、`writeToSheet` 接口。持久化全部列及勾选状态，提交时仅发送勾选列。
- 修改 Excel `taskpane.html`、`taskpane.js`、`taskpane.css`、`ribbon.js` 与图标资产：输入、设置和预览呈现。避免把解析、模型调用逻辑加入庞大的窗格文件。
