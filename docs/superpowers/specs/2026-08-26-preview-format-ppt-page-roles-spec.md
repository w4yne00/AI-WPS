# 结果预览渲染、格式问题卡片与幻灯片页角色

GitHub Issue #101。依据 grilling 共识与 ADR-0122。任务窗格直接渲染结构化数据；Markdown 只用于复制或导出。领域词以 `CONTEXT.md` 为准。

## Problem Statement

用户在 Word、Excel、PPT 任务窗格看结果时，预览经常是 Markdown 源码：标题、列表、表格和加粗没有变成可读文档。Word 对照若被改成源码，还会丢掉已经存在的原文/结果高亮。Excel 的「汇报段落」若被改名叫纯文本，会把另一份可粘贴简述收成报告源码。

格式审查完成后，问题操作条排版错乱：定位原文、标记已处理、标记已忽略和位置句挤在同一行，窄窗里按钮插进句子或折到下一张问题上方。预览里的问题清单和详细说明大量显示「当前值：无法识别」「模板要求：无法识别」，章节标题被写成图表题，题注关联被说成不符合模板；一单可以出现数百条「全文 · 其他格式项（锚点未验证）」，用户无法核对，也无法判断是真违规还是识别失败。

PPT 结构审查没有封面、目录、过渡、正文、结束等页角色。目录页和结束页被正确抽成空主标题后，本地规则一律报缺标题；局部审查还可能把页段首页当成封面。用户要求按前后页关系识别页角色、减少误报，而不是先改提示词。

## Solution

预览按受限 Markdown 预览语法渲染为可读文档；对照保持智能编写的已渲染高亮；纯文本才是源码。Excel 继续使用分析报告和汇报段落，不改名。格式审查问题清单不经预览渲染。

格式审查操作面改为问题卡片：独立操作条，展示位置、角色、题注关联结论或格式审查用户显示值、说明和建议。预览顶部只留覆盖和计数摘要。题注关联显示已关联、孤立、缺失或歧义，不得用无法识别冒充关联结论，也不得编造字号或对齐。生产快照必须带上节与正文故事身份，题注锚点必须指向真实段落，消除标题被标成图表题的串段和题注洪水。

结构审查在合并本地发现之前先判定幻灯片页角色。页角色用户可见。目录页和结束页豁免缺标题等规则；封面缺标题仍报；过渡页不豁免缺标题和重复标题；未确认按正文页执行。封面和结束只按整套文稿页码识别。首版不读版式名，不读有标题页正文。模型不得覆盖已确定角色。

## User Stories

1. As a Word 用户, I want 智能编写预览把标题、列表、表格和加粗渲成可读文档, so that 我不必自己读 Markdown 源码
2. As a Word 用户, I want 结果没有明显结构时预览仍然渲染, so that 一段正文也不会退回源码墙
3. As a Word 用户, I want 对照继续并排展示原文和编写结果并对插入内容高亮, so that 我能看出改了什么
4. As a Word 用户, I want 对照不是 Markdown 源码, so that 高亮对照不会被拆掉
5. As a Word 用户, I want 纯文本保持未渲染源码, so that 我可以核对或复制原文形态
6. As a Word 用户, I want 复制按钮仍复制模型结果文本而不是 HTML, so that 贴到 Word 里不会带标签
7. As a Word 用户, I want 写回不取决于当前结果视图, so that 我在预览或纯文本下写回的是同一份结果
8. As a Word 用户, I want 智能仿写继续不提供对照, so that 没有原文可对的任务不会出现空对照
9. As a Word 用户, I want 预览不执行原始 HTML、脚本、在线图片和示意图代码, so that 模型报告不能在任务窗格里跑代码或拉外网图
10. As a Word 用户, I want 预览里的链接只显示文本、不在任务窗格内跳转, so that 窄窗里不会被带出 WPS
11. As a Word 用户, I want 窄窗里的表格变成可读块而不是挤扁的宽表, so that 表头和单元格还能对上
12. As a PPT 用户, I want 智能总结预览按同一套受限语法渲染, so that 列表、加粗和表格不再像源码
13. As a PPT 用户, I want 后台只返回非结构化回答时预览仍然渲染, so that 降级结果也不会被强制显示成源码
14. As a PPT 用户, I want 纯文本查看源码, so that 我仍能复制未渲染文本
15. As an Excel 用户, I want 按钮继续叫分析报告和汇报段落, so that 我不会把可粘贴简述当成报告源码
16. As an Excel 用户, I want 分析报告按预览语法渲染, so that 结构化结论可读
17. As an Excel 用户, I want 汇报段落保持可粘贴纯文本, so that 我能直接贴进汇报
18. As an Excel 用户, I want 公式助手不出现这组视图切换, so that 短结果不被多一个无关开关
19. As a Word 用户, I want 格式审查问题清单不走预览 Markdown, so that 操作按钮不会再和报告源码缠在一起
20. As a Word 用户, I want 每条格式问题实例是一张卡片, so that 位置说明和操作不会挤在同一行
21. As a Word 用户, I want 卡片第一行是定位原文、标记已处理、标记已忽略, so that 三个操作始终在操作条里
22. As a Word 用户, I want 窄窗里三个按钮只在操作条内折行、不拆进正文, so that 不会再出现按钮插在「第 N 段」中间
23. As a Word 用户, I want 卡片操作条复用文档审查已经熟悉的卡片交互, so that 两个审查任务的处理方式一致
24. As a Word 用户, I want 预览顶部只看到覆盖和计数摘要, so that 操作面不再叠一份重复的问题表
25. As a Word 用户, I want 问题清单表和详细说明只出现在导出的 Markdown 或 JSON, so that 复制和归档仍有完整报告
26. As a Word 用户, I want 题注关联问题显示孤立、缺失或歧义, so that 我知道要核对的是关联关系而不是字号
27. As a Word 用户, I want 没有关联结论时不要写无法识别, so that 无法识别只用于没有可靠格式映射的显示值
28. As a Word 用户, I want 真有字号或对齐事实时仍看到小四、两端对齐这类用户显示值, so that 普通格式违规仍然可读
29. As a Word 用户, I want 系统不要为题注关联编造字号或对齐, so that 结论不会看起来像排版检查
30. As a Word 用户, I want 「整改建议」「核心漏洞汇总」这类标题不要被写成图表题, so that 我不会去图里找一个不存在的题注
31. As a Word 用户, I want 题注问题定位到真正的题注或图表段落, so that 点定位原文不会跳到错误标题
32. As a Word 用户, I want 生产文档不会因为缺少节和正文故事身份就刷出几百条题注问题, so that 问题清单反映真实违规
33. As a Word 用户, I want 「全文 · 其他格式项（锚点未验证）」不再成为默认噪声, so that 首页不再被无法处理的条目占满
34. As a Word 用户, I want 锚点未验证时定位原文禁用而不是消失, so that 我知道这条不能跳转，而不是找不到按钮
35. As a Word 用户, I want 继续按规则、严重程度、数据状态和原文顺序筛选分页, so that 长清单仍可处理
36. As a Word 用户, I want 标记已处理和标记已忽略仍按问题实例独立保存, so that 相同文案的不同位置不会共用状态
37. As a Word 用户, I want 需要确认的格式角色仍作为待核对项出现, so that 证据不足时不会被默认成正文或图表题
38. As a Word 用户, I want 题注位置是否合规与题注关联结论分开显示, so that 关联成立但位置不对时仍能单独处理
39. As a Word 用户, I want 未映射的字体继续显示无法识别而不是原始字体名, so that 界面不把机器值当成结论
40. As a Word 用户, I want 导出 JSON 仍包含机器字段和规范值, so that 诊断和二次处理不依赖中文文案
41. As a PPT 用户, I want 结构审查给出每一页的页角色, so that 我能核对封面、目录、过渡、正文和结束有没有认错
42. As a PPT 用户, I want 看到单独的页角色清单，包含页码、角色和一句依据, so that 误报可以对照证据验收

## Implementation Decisions

- 本规格覆盖三件独立但一次提出的事：任务结果视图渲染、格式问题实例展示与题注关联结论、幻灯片页角色及规则豁免。实现按三路提交，互不把对方的失败当成自己的完成条件。
- 预览使用既有受限 Markdown 预览语法：标题、段落、加粗与斜体、列表、引用、分隔线、代码、受控链接、表格。禁止原始 HTML、脚本、在线图片和示意图代码。窄任务窗格中的表格以可读块呈现。
- Word 预览在没有结构检测命中时也必须渲染。对照保持已渲染的原文/结果高亮，不改为源码。纯文本使用未渲染文本。复制和写回不读取当前视图。
- Excel 视图名称保持分析报告和汇报段落。分析报告走预览渲染，汇报段落走未渲染简述。不得把汇报段落改名为纯文本。
- PPT 智能总结预览与 Word/Excel 使用同一套预览语法。非结构化降级回答不得把预览强制改成源码。结构审查结果不经这组预览/纯文本切换，继续走结构化结果区域。
- 格式审查任务窗格直接渲染结构化问题卡片，不经预览 Markdown 拼操作按钮。卡片第一行是操作条，其后才是位置、角色、题注关联结论或格式审查用户显示值、说明和建议。锚点未验证时定位原文禁用，不隐藏。
- 预览顶部只保留覆盖状态和计数摘要。问题清单表与详细说明只进入导出 Markdown/JSON。筛选、分页、导出和按问题实例保存处理状态保持不变。
- 题注关联结论是受控展示值：已关联、孤立、缺失或歧义。它不是格式审查用户显示值。没有关联结论时不得显示无法识别。没有可比格式事实时不得生成或编造字号、对齐等显示值。
- 格式语义角色不得仅因数组下标或邻近图表把标题写成图表题。题注问题的稳定格式锚点必须指向对应题注或图表内容块，不能把块下标当作段落号。
- 格式审查快照必须携带判定题注关联所需的节与正文故事身份。缺少这些身份时不得把全部题注打成孤立、把全部表打成缺失。测试夹具不得再靠手写身份掩盖生产路径。
- 无法识别继续只表示格式审查用户显示值没有可靠中文映射，尤其是未映射字体。机器协议继续使用稳定字段，不把中文文案写入问题身份。
- 结构审查在合并本地发现之前判定幻灯片页角色。首版类型为封面、目录、过渡、正文、结束；证据不足为未确认页角色。
- 页角色证据顺序：整套文稿中的位置与邻页关系、已抽取标题链、形状名。首版不读版式名，不为区分过渡与正文读取有标题页正文。
- 封面和结束只按整套页码识别，不得把本次审查页段的第一页或最后一页升格。第 1 页不是封面的充分条件。中段目录仍是目录。
- 过渡页仅当主标题为章节形态标题且后页为同编号子节。过渡页即使实际含要点，首版仍标过渡。
- 页角色规则豁免：目录页和结束页豁免缺标题、无标题信息不足、重复标题和标题过长；封面页不豁免缺标题；过渡页不豁免缺标题和重复标题；未确认按正文页执行。编号跳号只作用于参与编号的过渡页和正文页。
- 结构审查结果必须向用户展示页角色清单（页码、角色、一句依据），并在逐页建议上标注角色。智能总结的自由角色不得进入结构审查。
- 模型语义审查只能处理仍模糊的页，不得覆盖已确定角色，也不得单独改变规则豁免。无模型时确定性页角色和本地规则仍须给出结果。
- 本决策以 ADR-0122 和 `CONTEXT.md` 中的任务结果视图、题注关联结论、幻灯片页角色及页角色规则豁免为准。不先改结构审查提示词来认页类型。

## Testing Decisions

- 好的测试只断言用户可观察的外部行为：某个结果视图里看到的是渲染文档还是源码、卡片操作条是否独立于位置句、题注问题展示的是关联结论还是无法识别、某页是否被标为某一页角色、该页是否出现缺标题。不锁定内部函数名、DOM class 字符串清单或 helper 调用顺序。
- 第一处缝：插件任务结果视图。输入为已完成任务的结果模型和当前视图。覆盖 Word 预览在有结构和无结构时均渲染受限语法；对照保持高亮渲染；纯文本为源码；复制文本不是 HTML。覆盖 PPT 预览在结构化结果和非结构化降级时均渲染，且纯文本为源码。覆盖 Excel 分析报告渲染、汇报段落未渲染、名称不被改成预览/纯文本。覆盖禁止原始 HTML 和在线图片进入预览。
- 第二处缝：格式审查问题实例。Adapter 侧覆盖：生产形态快照（节与正文故事身份按正式抽取合同提供）不再把全部题注打成孤立或缺失；题注问题的锚点对应真实内容块而不是块数组下标；关联结论进入结构化问题，导出和界面映射不再把关联 JSON 显示成无法识别；未映射字体仍显示无法识别。任务窗侧覆盖：问题以卡片呈现，操作条与位置句分离；预览不出现重复的问题清单表作为操作面；锚点未验证时定位原文不可用。
- 第三处缝：结构审查结果。Adapter 侧覆盖：目录页和结束页空主标题不产生缺标题；封面缺标题仍产生缺标题；过渡页由章节形态标题加后页子节认定，且仍报告重复标题；未确认页按正文执行；局部页段不把第一页升格为封面、不把最后一页升格为结束；无模型时仍有页角色和本地规则。任务窗侧覆盖：页角色清单和逐页建议标签使用返回的页角色，不读取智能总结角色。
- 先例：插件结果 Markdown 渲染测试、确定性格式审查可读值与问题页测试、格式规则包题注关联测试、格式审查快照协议测试、结构审查本地发现与去重测试、PPT 标题抽取测试。必须改写「任意空标题都必须出现一条缺标题」中与目录/结束冲突的部分，不能继续固化误报。有标题页正文读取次数为零、未映射字体不得漏出原始名，这两条既有红灯必须保留。
- 不把麒麟 WPS 真机操作条折行或真机 COM 版式名作为本规格自动化门禁。窄窗卡片折行用任务窗布局契约或夹具宽度覆盖；页角色不依赖版式名。

## Out of Scope

- 不把对照改成 Markdown 源码，不新增第四种「差异」视图。
- 不把 Excel 分析报告/汇报段落改名为预览/纯文本，不给公式助手加这组切换。
- 不引入第三方 Markdown 库，不渲染 mermaid，不在任务窗格内打开链接。
- 不把格式审查问题清单改回「先拼 Markdown 再渲染按钮」。
- 不编造格式审查用户显示值，不把关联 JSON 或原始枚举直接展示给用户。
- 不把智能总结的自由角色、版式名或有标题页正文作为结构审查首版输入。
- 不先改结构审查系统提示词来识别页类型，不把页角色做成只给算法用、界面不可见的隐式字段。
- 不自动创建、删除、重排或修改幻灯片。
- 不修改已冻结交付候选的字节和验收结论。
