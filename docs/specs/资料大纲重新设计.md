# 资料大纲重新设计

日期：2026-09-29。状态：设计与实施计划已获用户确认，2026-09-30 完成源码改造及自动化回归；真实 WPS DOC 转换与实际模型识图仍待验收，未发布安装包。

## 目标与完成标准

用户上传 DOCX、DOC 或复用其他文档的材料，将完整文字、表格和原图作为模型输入，结合编写要求、汇报对象和预定页数，生成可编辑、可追溯的逐页大纲编写建议。

完成标准：全部支持范围内的内容实际进入请求；不以摘要或相关片段替代全文；预览以建议为主、出处下钻；资料大纲具有独立且实际生效的模型参数；现有确认大纲与后续 PPT 生成衔接保持有效。真实 WPS DOC 转换与真实模型识图须单独验收。

## 已确认的产品设计

### 材料与完整输入

- 统一材料区提供“上传文档”和“复用材料”，支持 DOCX/DOC。沿用现有最多五份资料及文件安全限制，所有已添加且有效的材料参与生成，不增加隐藏筛选。
- 列表显示文件名和读取状态，文字、表格、图片数量及读取详情按需展开。读取失败、原件缺失或对象未完整读取须显示明确问题，不能标为全文就绪。
- DOC 使用 WPS 原生能力转换受保护的本机临时副本，关闭宏与自动外链更新，完成后关闭临时文档、清理临时文件并恢复宿主状态，不改变原文件。PPT 宿主调用 Word 转换能力必须在目标机验证，不能以 Word 宿主已有模拟测试代替。
- 复用保留现有资料归属和独立副本语义。必须获得完整原件及来源信息，旧片段记录不足以满足全文输入时要求重新上传。其他宿主的非 Word 材料不纳入本轮格式扩展，不将其片段伪装成完整 Word 文档。
- 读取正文、标题、列表、表格行列与合并关系、文本框、页眉页脚、脚注尾注及可提取原图，保留内容顺序、图片锚定及文件来源。共享读取器现有能力不足时明确补齐或报错，不静默漏读。
- 扫描页作为原图提交。原生图表、公式、绘图、嵌入对象和外链图片无法可靠读取时列明对象并阻止生成；不执行材料内宏、附件、外链或指令。
- 完整文字、表格和原图同时交给支持图片的模型；不自动 OCR 替代原图、不删图、不压缩为摘要、不分段汇总。模型不支持图片、能力未知或服务拒绝图片时明确提示，不降级重试为纯文本。
- 沿用现有原图通道限制。预算包括系统提示、编写要求、全文及输出预留；图片开销没有可靠估算时明确标为未知，由服务最终核验，不声称总容量已精确验证。超限提示更换模型或由用户主动减少材料，保留现有文件安全上限并区分两类限制。

### 编写与逐页建议

- 主流程为“添加材料 → 填写编写要求 → 生成逐页大纲 → 预览使用”。汇报对象、预定页数保留当前默认值和页数选项，不在本轮扩大范围。
- 将重点要求统一标为“编写要求”。补充事实默认收起，有已填内容时显示提示，允许查看与清空，不能让隐藏旧输入无提示参与生成。
- 每页展示页码、标题、核心观点、内容要点和表达建议，按汇报对象与用户提示组织内容。预定页数指整套大纲总页数，包括封面、目录等实际输出页面；不得多页或少页而声称完成。
- 保留现有页面角色、逐页编辑、复制、确认大纲及后续模板生成衔接。核心观点与表达建议为补充信息，不混入原有要点字段以规避下游约束；旧结果缺少新增信息时正常显示，不补造内容。
- 事实缺少依据时标为待补充；模糊图片或不确定识别标为待核对。保留现有事实冲突处理，不让模型自行裁决互相冲突的数字或来源。
- 生成只产出大纲，不修改幻灯片。资料、编写参数或大纲变更后沿用重新确认规则；保留现有后续生成与写入的独立确认和安全措施。

### 结果预览与出处下钻

- 逐页建议占满预览宽度，不常驻并排来源面板。每页只保留轻量“出处”入口。
- 点击后在同一预览区展示对应文件、章节、原文或图片，并提供“返回大纲”；返回恢复原滚动位置与键盘焦点，参考 Word 按需编写现有行为。
- 原文页码仅在可靠时显示，否则使用章节、段落或表格定位。生成的大纲页码与原文位置明确区分，不编造来源页码。
- 缺项与待核对项默认显示数量，点击下钻。资料失效、内容未完整读取和输出未完成等影响使用的提示始终可见。
- 普通刷新保持当前详情阅读，切换演示文稿或生成新任务重置详情。出处按钮和界面状态不混入复制文本或后续 PPT 内容。

### Apple design 与图标

- 使用系统字体、清晰留白和克制层级；主流程突出材料、编写要求、汇报对象、页数及一个生成按钮，模型参数放入设置。
- 按钮即时反馈，读取和生成显示真实阶段，支持取消，失败保留输入。下钻与返回保持空间关系，兼容窄窗格、键盘、可见焦点及减少动效偏好，不为动画新增依赖。
- 新图标采用“文档＋分层条目”，替换现有智能总结图标复用，沿用 Ribbon 的尺寸和资产格式；核对小尺寸辨识度，不单独建设图标系统。

### 独立模型设置

- PPT 设置新增“资料大纲”模型配置选项卡，使用已有任务标识 `ppt.material_outline`。
- 复用现有服务选择、任务模型、温度、最大输出 Token、上下文容量、保存及验证机制；默认值、空值与零值语义沿用其他编写功能，不另立参数规则。
- 参数实际进入本次模型调用和输入预算，提交时固定模型配置快照。更改本任务不改变智能总结、结构审查或其他任务配置。
- 使用既有图片能力配置和多模态请求通道；配置未知不能当作已支持。输出被截断、结构不合法或来源不合法时标为失败或未完成，不开放完整大纲确认。

## 实现边界与数据流

保留当前工作目录和分支，不创建 worktree，不修改运行态配置及用户已有未提交文件。优先复用既有能力；新增依赖须先说明并取得确认。

1. 材料层：调整 `adapter_service/app/services/ppt/material_store.py`，复用 Word 的 `material_document.py` 完整读取、安全 DOC 转换和原件保存能力。不得改变 Word 或 Excel 已有处理约定。
2. 生成层：调整 `adapter_service/app/services/ppt/material_outline.py` 及对应系统提示词，以完整内容和图片替代当前片段输入，保留来源映射、后台队列、取消、结构验证与确认状态。
3. 模型与接口：复用 `provider_client.py`、任务模型配置和图片发送能力，FastAPI 与 standalone 的导入、复用、生成及错误行为一致。普通提交传资料引用，完整输入由后端装配。
4. 窗格层：调整 WPP 的 `material-outline.js`、`taskpane.html`、`taskpane.js`、样式、Ribbon 图标映射及交付资产清单；借鉴 Word 下钻行为，避免跨宿主复制整套页面。
5. 下游兼容：保留已确认大纲的身份、页面角色和既有字段语义，新增建议字段须覆盖前后端解析、编辑与持久化。单页和整套 PPT 生成仍消费原有内容字段，回归确认失效与容量核验，不借此重构模板生成。

数据流：上传或复用 → 完整读取与来源登记 → 填写要求及选择模型 → 固定本次资料和参数 → 核对能力与容量 → 模型生成 → 校验页数、结构、出处与完成状态 → 全宽预览及下钻 → 用户确认后接入原有后续功能。

切换演示文稿、更新资料或取消任务时，迟到响应不得覆盖当前结果。旧结果保留所属会话，失效资料不能继续作为有效依据。来源标识必须能定位本次完整输入中的文字或图片，不接受模型虚构的来源。

## 验收与回归

1. DOCX/DOC 样本含文首、文中、文尾独立事实、表格和原图，检查实际模型请求完整包含内容和图片，而非仅检查最终回答。
2. 覆盖文本框、页眉页脚、脚注尾注、浮动图和扫描页；损坏、加密、未读取对象及缺失原件明确失败。
3. 验证复用独立副本、更新与移除、旧片段资料重导提示；真实 PPT 宿主验证 DOC 转换、原件不变、安全开关及临时文件清理。
4. 验证图片能力未知、不支持、图片大小与上下文超限、服务拒绝，不自动删图或截断。核对输入预算未重复计算系统提示，输出预留实际采用当前配置。
5. 验证提示词、汇报对象和页数进入请求并影响逐页建议；页数错误、输出截断、无效出处和缺项均有明确状态。
6. 在 320px、420px 窗格检查全宽预览、出处文字和图片下钻、返回位置与焦点、详情刷新和跨文稿重置，验证键盘和减少动效。
7. 保存并重开模型设置，检查温度、输出上限和上下文容量实际生效，其他任务配置不变；检查新图标小尺寸显示。
8. 回归逐页编辑、复制、确认失效、取消重试、关闭重开、资料更新及迟到响应；验证单页与整套生成仍可使用已确认大纲，生成大纲本身零幻灯片写入。
9. 运行受影响后端与插件测试，再执行仓库要求的 `npm test`、`npm run build`、`node --test formal-plugin-kit/tests/*.test.js`；后端按 `docs/operations/kylin-v10-test-environment.md` 使用当前虚拟环境解释器。完成 Python 3.8 兼容扫描、差异检查及相关交付装配审计回归。
10. 单独验证真实 WPS 操作与实际模型生成质量，报告通过数、失败数、关键问题、影响范围和未验证项；模拟或浏览器测试不能替代真机验收。

## 本轮范围外

不扩展 CSV/XLSX/PDF 导入，不建设知识库或检索系统，不增加自动长文分段汇总，不改造模板排版和写入逻辑，不新增写作规范功能，不自动发布安装包或修改现场模型配置。
