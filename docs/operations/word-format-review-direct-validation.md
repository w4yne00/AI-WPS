# Word 格式审查直连验证

格式审查使用共享直连服务，任务标识为 `word.format_review`。设置页选择服务、模型和任务参数后保存。目录模型确认会先验证格式语义协议，失败则保留原选择和草稿；手填模型及继承的手填默认模型可直接保存。验证只发送合成内容，不发送用户文档，并会产生模型费用。

验证成功只适用于被验证的服务 ID、完整服务端点、API Key、有效模型、温度、最大输出 Token、上下文容量和图片模式。修改这些字段后需要重新验证。只改变服务名称不影响验证。任务验证失败会撤销相同身份的旧成功；验证期间服务配置发生变化返回 `DIRECT_SERVICE_CONFIG_CHANGED`（409）。验证其他草稿不会把当前选择标记为已验证。

未通过格式语义验证时，格式审查仍可执行确定性规则，报告降级原因 `format_semantic_protocol_not_ready`。模型目录不可用或模型已被移除等配置错误仍沿用现有配置检查。

## 视觉验证

直连格式审查自动使用 `openai_image_url`，不再提供图片输入模式、授权图片外发或撤销授权。旧的关闭模式和缺失、撤销、失效授权按自动模式读取，不补写授权或探测通过记录。

1. 目录模型确认时自动完成格式语义验证和视觉探测。格式语义失败不保存。识图通过不能代替格式语义协议通过。
2. 手填模型保存后自动探测，不阻塞确定性审查。格式语义与视觉能力分别显示进行中、成功或具体失败原因；探测失败保留新选择。修改草稿或切换任务后，旧响应不覆盖当前状态。
3. “验证视觉能力”只探测当前已保存配置。有未保存修改时先确认，不把旧模型的结果记到新草稿上。探测只用系统生成的无敏感合成图片，不读取正在编辑的文档。
4. 管理员关闭图片语义总开关后，不创建真实文档导出槽、不导出 PNG、不发送文档图片。合成探测与真实图片使用分开。

服务、模型、凭据或相关参数变化后，旧视觉验证失效并需要重测。相同且仍然有效的探测不会重复发起；同一 Adapter 进程中，相同配置的进行中探测也共用一次模型调用，失败后可重试。验证期间选择变化时，旧响应不得覆盖当前选择。无有效视觉能力时跳过图片增强并披露覆盖范围，确定性审查仍可用。不得声称远端图片已删除。

## 公开接口

FastAPI 与 standalone 提供相同路径：

| 方法与路径 | 请求 | 行为 |
| --- | --- | --- |
| `POST /provider/task-model-selections/word.format_review/validate` | 任务选择草稿；省略时读取已保存选择 | 验证格式语义协议；草稿可在首次保存前验证 |
| `POST /provider/task-model-selections/word.format_review/image-authorization` | `authorized` 布尔值，可附 `expectedSelection` 和 `expectedServiceRevision` | 授权或撤销当前已保存选择；附带选择或服务版本与当前不一致时返回 409；任务窗格会携带两者 |
| `POST /provider/task-model-selections/word.format_review/validate-image` | 空对象探测已保存选择；带 `serviceId` 时探测该草稿且不改写其他已保存选择 | 发送合成图片并核对识别结果；不再要求图片授权。识别失败返回 502，并保留当前模型选择 |

图片接口返回 `data.taskModelSelection`。直连格式审查的 `imageSemanticReadiness.code` 为 `validation_required` 或 `ready`，不再用单独授权作为门禁。格式语义状态通过 `formatSemanticReadiness.code` 读取。工作流平台的图片模式和授权行为不变。

直连视觉验证接口只接受 `word.format_review`；其他任务在调用模型前返回 `DIRECT_SERVICE_TASK_UNSUPPORTED`（400），即使请求携带草稿也不会发送图片。

验证期间切换选择或轮换 Key，不能把原请求的结果写到新配置。视觉验证失败会清除同一绑定上的旧视觉成功记录，但不撤销已保存的模型选择。
