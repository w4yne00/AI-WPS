| 无变化播报 | 保持选区不变并停留任务页至少 10 秒，同时开启屏幕阅读器或可访问状态检查 | 低频兜底不重复改写或播报相同的范围摘要 |

## Excel 公式助手读取与只读边界（issue #21）

属性可用性记录：

| 属性 | 可读 | 返回类型/示例 | 降级结论 |
| --- | --- | --- | --- |
| `HasFormula` |  |  |  |
| `Formula` |  |  |  |
| `FormulaLocal` |  |  |  |
| `FormulaR1C1` |  |  |  |

测试任务窗格的实际降级顺序必须为 `Formula → FormulaLocal → FormulaR1C1`；`HasFormula` 明确为假时按普通值处理。属性不可用或读取异常时继续下一只读路径，三条路径均失败时不猜测公式。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 30×20 上限 | 框选 31×21 混合区域 | 只读取左上角 30×20，界面显示截断 |
| 空选区 | 让 Selection 无有效范围后运行公式助手 | 中文提示先框选范围，不回退 UsedRange、不提交任务 |
| 混合值/公式 | 同一区域放置文本、数字、空值、错误值和多个公式 | 有限类型和公式读取正确，普通文本不被误判为公式 |
| 超长/外部/兼容风险 | 分别测试超长公式、外部工作簿、URL/网络函数、越界引用、版本敏感函数 | 显示受控风险，只称基础检查，不称公式正确 |
| 独立工作流 | 切换两个 `excel.formula_assistant` 档案后分别提交 | 每个新任务命中提交时选择的档案 |
| 慢模型排队 | 占满两个共享运行槽位后提交公式任务 | 公式任务进入 FIFO，显示位置/阶段/耗时，排队时可取消 |
| 重开续查 | 任务运行中关闭再打开公式助手任务窗格 | 使用原任务号恢复，不重复提交模型调用 |
| 复制 | 分别复制结构化主公式/说明和非结构化原始结果 | 剪贴板内容正确，工作簿没有变化 |

每个场景执行前后记录：测试区域显示值与公式摘要、工作表名称和数量、计算模式。三项前后必须一致；任何赋值、填充、新建工作表或计算状态变化均判定失败。
