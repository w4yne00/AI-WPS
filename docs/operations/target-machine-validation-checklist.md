测试环境记录：

- `WindowSelectionChange` 是否实际触发：`是 / 否`
- 验收人及时间：`________________`

按下列顺序在 Word 任务窗格执行；“立即”以 1 秒内为验收口径，“低频兜底”以约 2 秒、最长不超过 3 秒为现场口径。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 事件路径 | 保持任务页可见且模型空闲，在正文和有效选区之间切换 | 若宿主实际触发 `WindowSelectionChange`，范围摘要立即在“全文 / 选中文本”间切换 |
| 事件漏报 | 在已确认事件可用的环境中连续用鼠标、键盘及跨窗口方式改变选区 | 漏报时范围摘要仍在 3 秒内由低频兜底修正，不会永久停留在旧范围 |
| 事件不可用 | 在不提供或不触发 `WindowSelectionChange` 的麒麟/WPS 组合上改变选区 | 页面不报错，范围摘要在 3 秒内更新；记录该环境使用兜底路径 |
| 页面隐藏 | 隐藏任务窗格后改变选区，等待至少 3 秒，再重新显示任务窗格 | 隐藏期间不持续刷新；重新可见后立即显示当前真实范围 |
| 设置页 | 进入设置后改变选区，等待至少 3 秒，再返回任务页 | 设置期间暂停选区读取；返回任务页后立即显示当前真实范围 |
| 模型任务 | 分别在四个 Word 任务请求运行期间改变选区 | 请求期间暂停无意义读取；任务完成或失败后立即恢复并显示当前范围 |
| 无变化播报 | 保持选区不变并停留任务页至少 10 秒，同时开启屏幕阅读器或可访问状态检查 | 低频兜底不重复改写或播报相同的范围摘要 |

回归检查：

- [ ] 智能编写仍要求有效选区，抽取和写回仅作用于原选区边界。
- [ ] 智能仿写仍只将选区用于模板预填，结果保持预览/复制，不新增写回。
- [ ] 文档审查仍按选区优先、无选区全文的既有边界工作，并保持后台任务恢复。
- [ ] 格式审查仍按既有限量抽取和只读结果工作。

- 任务窗格视口：`420×900 / 320×700 / 其他：________`
- 验收人及时间：`________________`

按下列顺序在 Excel 任务窗格执行；“立即”以 1 秒内为验收口径，“低频兜底”以约 2 秒、最长不超过 3 秒为现场口径。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 事件路径 | 保持任务页可见且模型空闲，在同一工作表切换不同地址和行列规模的选区，再切换工作表 | 若宿主实际触发 `SheetSelectionChange`，范围类型、工作表、地址和行列摘要立即更新 |
| 事件漏报 | 在已确认事件可用的环境中连续使用鼠标、键盘、名称框及跨工作表方式改变选区 | 漏报时范围摘要仍在 3 秒内由低频兜底修正，不会永久停留在旧范围 |
| 事件不可用 | 在不提供、不允许注册或不触发 `SheetSelectionChange` 的麒麟/WPS 组合上改变选区 | 页面不报错，范围摘要在 3 秒内更新；记录该环境使用兜底路径 |
| 页面隐藏 | 隐藏任务窗格后改变选区，等待至少 3 秒，再重新显示任务窗格 | 隐藏期间不持续读取工作表对象；重新可见后立即显示当前真实范围 |
| 设置页 | 进入设置后改变选区，等待至少 3 秒，再返回任务页 | 设置期间暂停范围读取；返回任务页后立即显示当前真实范围 |
| 模型任务 | 提交智能分析，在排队、运行及结果返回前改变选区 | 模型任务期间暂停范围读取；任务终止后立即恢复并显示当前范围 |
| 无变化播报 | 保持选区不变并停留任务页至少 10 秒，同时开启屏幕阅读器或可访问状态检查 | 低频兜底不重复改写或播报相同的范围摘要 |
| 提交时实读 | 等范围摘要显示选区 A 后立即切换到选区 B，并点击“开始智能分析” | 提交数据来自点击后的真实选区 B，不以先前摘要或缓存数据代替 |
| UsedRange 兜底 | 让当前 Selection 无有效数据，但当前工作表 UsedRange 含有效表格后提交 | 仍按既有逻辑读取 UsedRange；行列、单元格和总文本预算保持不变 |
| 窄窗布局 | 分别将浏览器模拟任务窗格设为 420×900 和 320×700，检查任务页与设置页 | 页面无横向溢出；范围摘要、主按钮和设置入口不被裁切或重叠 |
