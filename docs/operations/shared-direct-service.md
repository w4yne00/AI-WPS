# 共享直连服务

Word、Excel、PPT 九类任务共用同一本地 Adapter 运行环境中的直连服务配置。工作流平台继续按功能独立配置，不走本页合同。

九类任务标识：`word.smart_write`、`word.smart_imitation`、`word.document_review`、`word.format_review`、`excel.analysis`、`excel.formula_assistant`、`excel.smart_fill`、`ppt.slide_assistant`、`ppt.structure_review`。

## 录入与保存

1. 打开任一宿主设置首页的“共享直连服务”。
2. 新建服务时填写名称和规范化服务地址；API Key 只录入一次，保存后页面只显示“已配置”，不回显明文。
3. 同一运行环境最多五份服务。地址或 Key 任一不同都视为不同服务，不得合并。
4. 保存或更换地址、Key 后立即读取 `<serviceBaseUrl>/models`。也可手动刷新。目录契约见 `direct-service-model-catalog.md`。
5. 每个服务可设置默认模型。尚未单独覆盖的功能继承该默认值；任务页必须显示本次实际模型。
6. 保存服务只验证地址、认证和模型目录，不自动执行九类付费任务验证。

## 任务选择

功能设置页只选择已有共享直连服务，并覆盖模型标识、温度、Token 和图片参数。工作流平台配置仍按功能独立保存，互不影响。

任务提交冻结调用方式、服务身份、配置修订、Key 指纹、模型标识和任务参数。之后修改配置不得静默改变已提交任务。

已选模型从新目录消失时，须阻断新任务，不得自动改选。

## 修订冲突

共享服务每次保存递增 `revision`。编辑端必须携带自己读到的修订号。修订已变化时返回 `DIRECT_SERVICE_REVISION_CONFLICT`，须刷新后重新编辑，不得用旧页面覆盖。

## 引用删除

被任一任务引用的服务不得删除，错误码为 `DIRECT_SERVICE_IN_USE`，响应列出引用功能。须先把这些功能改到其他服务或工作流平台。

修改服务地址前须披露受影响功能。地址变化按新服务身份处理。

## Key 轮换

替换或清除 Key 不保留旧副本。引用旧 Key 指纹的排队、运行和可恢复任务须立即失败，并要求重新提交。已完成结果和历史不得因此删除。新任务使用新 Key。

关闭未保存草稿后，前端须清除本次 Key 明文。

## 旧直连迁移

升级时按规范化地址和 Key 指纹合并旧任务直连配置。地址或 Key 任一不同都形成不同服务；原模型和任务参数保留为各功能的任务模型选择。不完整配置只成为未启用草稿。超过五份不同服务时进入受限状态，不得擅自删除。迁移失败须保留原运行数据，可按一致性快照整体回滚。

## 故障排查

1. 三宿主设置首页应看到同一组服务；若不一致，先核对是否连到同一 Adapter。
2. 任务页看不到直连选项时，检查服务是否已配置 Key 且模型可用。
3. 保存失败返回修订冲突时，刷新服务后再改。
4. 删除失败时按引用功能列表先改任务选择。
5. Key 轮换后未结束任务失败是预期行为，须重新提交，不得等待自动恢复。
