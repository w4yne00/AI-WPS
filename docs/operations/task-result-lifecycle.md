# 活动任务结果与只读历史

活动任务结果按宿主、功能和文档会话隔离。历史结果列表与活动区分离，只保存成功输出。失败和取消不进入历史。

## 活动任务结果

本地校验通过并准备发送、将产生新任务编号的提交，才是新任务。此时旧结果须立即退出活动区；本次失败只显示本次错误，不得回退旧结果。

分页、预览切换、填写项编辑、目标选择、返回修改、复制、导出和审查问题状态操作不是新任务，不得清除当前业务结果。

文档会话使用非敏感内部标识，不得用完整路径作为隔离键。切换文档只显示目标会话的活动结果。同名文档仍按会话隔离。

## 活动任务槽位

一个功能在一个文档会话中只允许一个未结束任务。槽位被占用时拒绝重复提交。不同功能或不同文档会话仍可在 Adapter 总容量内并发。

活动任务恢复必须匹配宿主、功能和文档会话，且任务仍在排队或运行。已完成任务不得通过活动恢复重新载入活动区。

## 历史结果列表

成功终态写入历史。入口位于各功能结果区，不在设置页。用户须主动打开；阅读历史时，新任务完成只更新提示和未查看计数，不得强制跳转。

历史按功能展示，标注文档显示名称、完成时间和任务编号，并保留模型服务名称和模型标识。普通文本可以查看和复制。支持单条删除和清空该功能历史。

历史在私有运行目录中原子写入，目录权限 `0700`、文件权限 `0600`。跨 WPS 与 Adapter 重启保留二十四小时。每个功能最多 20 条，单条最多 5 MiB，全部功能合计最多 100 MiB。超限时按完成时间删除最旧项。超过单条上限的普通结果不归档，并在活动区提示。

## 安全边界

历史结果快照不得保存原始输入、完整文件路径、API Key、完整请求体或响应头。查询、诊断和落盘文本均不得回显这些字段。

智能填写历史不得再次写回或重试，也不保存写回映射。文档审查和格式审查历史只保存受限摘要和仍在有效期内的专用报告入口；入口过期须明确提示，不得表现为可恢复。

## 故障排查

1. 新任务仍显示旧结果时，先确认本次提交是否已通过本地校验并真正发出。
2. 两个文档串用结果时，核对文档会话是否变化，而不是只看文件名。
3. 历史看不到失败任务是预期行为。
4. 智能填写历史没有写回按钮是预期行为。
5. 专用报告入口失效时，只提示过期，不得从历史恢复定位或处理状态。
