# 限制格式语义重试、纠正和等待时间

决定格式审查模型语义阶段最长十分钟、单次调用最长六十秒；超时、限流、服务端错误或连接中断最多重试一次，认证、模型、路径或配置错误不重试。响应未通过完整 JSON Schema 时最多发起一次受控纠正调用，仍不合格则拒绝整批操作，不从结构无效响应中选择部分结果。全部重试和纠正请求均计入十六次格式语义调用预算；取消请求会阻止后续调用，无法可靠中止的在途 HTTP 请求返回后丢弃结果。最终失败不推翻确定性检查，必需格式语义未决使相关规则无法判定、覆盖状态为部分且合规状态为无法判定，仅可选格式语义失败则只使语义增强状态降级。该策略以较低的瞬时故障恢复率换取可预测的调用量、时延和结果完整性。
