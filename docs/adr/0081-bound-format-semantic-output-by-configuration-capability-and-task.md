# 按配置、模型能力和任务上限约束格式语义输出

决定格式审查在工作流平台模式使用工作流明确的最大输出限制，当前为 `2048` Token；模型直连模式优先读取当前配置的 `maxOutputTokens`，未填写时按精确模型标识查询随版本离线发布且标注官方来源日期的能力表。官网最大输出只表示模型能力上限，不等同于服务端未传 `max_tokens` 时的默认值；格式审查的有效语义输出预算固定为配置值或能力上限与任务上限的较小值，首版模型直连任务上限为 `4096` Token。无法唯一匹配精确模型时不按厂商名称猜测，确定性审查继续完成，但模型语义补充保持未就绪并提示补充最大输出配置。该约束牺牲按超大输出上限扩大单次批次的可能性，以限制异常输出、延迟和费用，并保持不同接入方式下的批次计算可预测。
