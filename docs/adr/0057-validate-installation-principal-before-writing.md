# 安装写入前验证目标用户和目录归属一致

虽然本次现场故障已经确认由 Python 3.8 不兼容注解引起，而不是 `sudo` 导致的用户目录分裂，安装器仍必须防止同类部署风险。决定安装器在任何写入和切换前验证安装主体一致性：默认只允许当前 WPS 登录用户以非 `root`、非 `sudo` 方式运行，插件目录、Adapter 目录和运行数据目录必须属于同一明确 UID、主目录必须真实存在且目标可写；任一条件不满足时保持原状态并停止，不得静默递归 `chown`。后续若需要管理员代装，只能显式指定 `--target-user`，并验证该用户的 UID、主目录和 WPS 插件位置，不能使用 `root` 的 `$HOME` 推断目标。该规则降低了安装便利性，但避免把配置、密钥、插件和进程拆到不同用户上下文，或用破坏性的权限修正掩盖既有问题。
