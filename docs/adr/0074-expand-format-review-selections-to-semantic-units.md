# Word 选区格式审查扩展到完整语义单元

决定保留“有有效选区时审查选区、无选区时审查全文”的现有操作习惯，但格式审查不直接以字符边界为结构边界。部分段落扩展为完整段落，选中表格单元格扩展为完整表格，图、表与题注成组读取，列表项读取前后相邻列表上下文，标题读取最近上下级标题，同时读取所在节的页面属性。界面必须展示实际扩展范围。

额外读取的对象属于选区格式上下文，只参与范围内对象的角色、连续性和关联判断，不能产生范围外问题或计入已审查对象数量。目录完整性、全文标题连续性和全文编号连续性等需要完整文档的规则在选区模式中不执行，并明确列入“未执行全局格式规则”，不得标记为通过。该策略增加选区解析复杂度，但避免在半个段落、半个表格或缺失相邻题注的情况下产生错误结论，同时保持局部审查不会突然报告全文问题。
