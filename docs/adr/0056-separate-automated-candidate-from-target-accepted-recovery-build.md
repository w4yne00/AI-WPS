# 自动化候选构建与目标机已验收恢复构建分级

决定自动化 Python 3.8 目标运行时门禁通过后，仅将 `v0.23.1-alpha` 标记为候选构建，允许安装到测试目标机；只有在麒麟 V10、目标 WPS 和 `cloud` 登录用户环境中完成真实覆盖升级，验证 Adapter 持续监听 18100、WPS 重连、原八类工作流配置及 Key 引用和当前选择保持、模型配置可新建保存切换、写作规范库恢复、重启后状态保持，并确认日志与验收材料不含 API Key 明文后，才能标记为已验收恢复构建并宣称现场故障解除。该分级增加一次人工目标机验收和状态管理，但避免把开发或容器环境测试等同于麒麟/WPS 现场恢复证据。
