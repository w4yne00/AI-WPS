# 将授权确定性算法与权威格式规则包分离交付

Issue #46 在 Issue #42 和 #45 关闭后实施。授权 `wx-doc-format-skill` v0.12.15
只以内置 Python 3.8 兼容适配提供标题层级、列表、表格、题注、附录和注语义识别；
适配器只接收 WPS 结构化快照事实，不包含 DOCX 转换、排版写回或模型推断。

AI-WPS 权威模板值由构建期从版本化模板 DOCX 提取，人工审定的结构规则清单单独
编译进入只读规则包。规则包记录源文档哈希、规则来源、适用对象、单位、容差、
严重级别、算法版本和完整性哈希。运行时加载失败或完整性不匹配时不接受该规则包，
也不以授权算法中的默认样式、模板值或自动排版逻辑替代。

发布使用聚焦的 v0.25.0 格式规则资产白名单，构建时重新编译并逐字节比较规则包，
再执行 Python 3.8 兼容扫描和精确文件审计。资产包状态为 `candidate`，仍须通过
后续整合版本的目标机验收。
