# 运行数据通过写时复制和原子切换迁移

旧模型配置、API Key 引用和写作规范数据属于升级过程中不可丢失的运行状态。决定升级前先生成原数据的脱敏清单和校验信息，将数据复制到隔离位置，只在副本上执行迁移；副本必须通过八类任务配置数量、服务地址、Key 引用、激活关系、规范库结构和数据库完整性验证后才原子切换。任一步失败都保持对应原数据不变；核心模型配置或任务路由迁移失败使新 Adapter 进入恢复模式，仅写作规范等非核心增强数据失败则进入降级状态并沿用规范降级契约。API Key 仅检查文件或引用是否存在及不可逆指纹是否一致，任何安装、迁移、诊断和验收日志都不得输出明文。该方案增加临时磁盘占用、校验步骤和原子切换实现成本，但消除了原地迁移留下半完成状态或破坏唯一可恢复副本的风险。
