# Word 全篇审查要求显式配置输入与输出容量

模型直连配置只有在显式保存上下文窗口 Token 和最大输出 Token 后才具备 Word 全篇审查能力，历史空值不自动填充；最大输出低于 2,048 时不开放全篇审查，推荐值为 8,000。Adapter 按显式容量计算分片输入预算，并在每次分片和汇总请求中发送 `max_tokens`；设置页分别披露限量审查与全篇审查就绪度。

现有配置允许最大输出留空，此时 Adapter 按默认 8,000 Token 预留输入预算，却不向 Provider 发送对应上限，服务端实际默认值可能更小，使结构化问题列表和饱和判断不可预测。要求管理员确认真实容量会使部分历史配置暂时不能执行全篇审查，但避免将本地估算值误认为模型服务已经接受的能力。
