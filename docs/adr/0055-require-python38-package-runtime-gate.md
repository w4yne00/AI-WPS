# 最终交付包必须通过 Python 3.8 目标运行时门禁

`v0.23.0-alpha` 的不兼容注解能够通过更高版本 Python 和静态语法检查，却在目标 Python 3.8 导入类定义时立即崩溃。决定 `v0.23.1-alpha` 及后续版本必须对最终交付包执行阻断式 Python 3.8 运行验证：完整导入应用、真实启动 Uvicorn、校验 `/health` 返回版本及关键配置接口；分别覆盖全新安装、从携带八类任务配置、Key 引用和写作规范数据的 `v0.22.0-alpha` 升级；注入核心配置损坏验证恢复模式和原数据不变，注入写作规范数据损坏验证降级状态和 Word 核心任务继续；注入不可导入候选包验证事务式升级不切换旧版本。源码编译、静态扫描及 Python 3.9 以上测试可以作为补充，但不能替代该门禁，任一检查失败都不得把构建标记为可交付。该门禁增加构建环境和集成测试成本，但直接覆盖正式支持的最低运行时及本次漏检路径。
