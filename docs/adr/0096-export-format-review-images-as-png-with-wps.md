# 使用 WPS 将格式审查图片只读导出为 PNG

> 发布门禁状态已由 ADR 0108 调整：实现随包休眠交付且默认关闭，不阻塞当前整合版本；实际启用前仍须完成目标环境验收。

决定首版不新增 Pillow 等图片处理依赖，也不从 Range OpenXML 直接发送 Word 保存的原始图片二进制；受支持的正文内嵌图片和图片型浮动形状由 WPS `SaveAsPicture` 只读导出为临时 PNG，再由 Adapter 校验并通过当前格式审查配置发送给后台模型。导出过程不得转换对象类型、移动图片、保存当前文档或使用原文件名，PNG 只绑定随机图片资产标识、稳定图对象组和格式快照指纹，并在任务终态立即删除。该路径避免直接发送原始图片格式及其 EXIF，但不提供 Adapter 侧缩放或重新压缩；PNG 格式、透明背景、尺寸、文件大小和视觉保真度必须在麒麟 WPS 12.1.2 真机门禁验证，失败时该图标记无法视觉审查而不修改文档或回退发送原图。
