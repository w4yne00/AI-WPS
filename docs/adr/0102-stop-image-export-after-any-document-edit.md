# 文档发生编辑后停止剩余图片导出

决定首版将图片增强阶段视为原格式审查快照的受控补充，不允许把旧格式事实与编辑后的图片内容混合。进入图片增强阶段时，任务窗格提示用户暂勿编辑；WPS 在每个原子图像语义批次导出前验证原文档身份、未发生编辑，并核对图对象锚点、类型、数量、尺寸、裁剪、旋转、Alt Text 和邻近文本指纹，调用 `SaveAsPicture` 后再次核对同一组指纹。自图片阶段开始检测到当前文档任意编辑，或者组级前后指纹不一致时，立即停止全部剩余图片导出，删除已导出但尚未发起模型请求的 PNG，不自动重建格式快照，也不继续使用变化后的图片。已经完成的确定性格式审查仍生成结果，未处理图片降级为 `text_evidence_only` 或 `not_assessable`，语义增强状态标记部分完成。该严格门禁牺牲编辑期间的图片建议连续性，以保持同一报告证据版本的一致性。
