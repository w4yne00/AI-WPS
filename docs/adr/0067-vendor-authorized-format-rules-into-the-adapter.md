# 将已授权格式规则作为受控内置分支纳入 Adapter

`wx-doc-format-skill` 作者已经授权 AI-WPS 使用其代码，本地取得的来源版本为 `0.12.15`。决定不让目标机运行时加载开发机目录或在线仓库，也不整包嵌入包含 DOCX 转换、重排和渲染的完整流水线；只将格式审查所需的确定性识别与审计核心作为授权规则内置分支纳入 Adapter，并通过适配层读取 AI-WPS 的格式语义模型。内置分支记录来源版本、文件哈希、授权说明、第三方声明和本地改造，所有生产代码改为 Python 3.8 兼容并进入白名单构建、引用闭包、单元测试和真实目标运行时门禁。

该方案保留授权代码的可追溯复用价值，同时支持 WPS 中尚未保存的实时文档和局部选区。代价是后续上游升级必须人工对照合并，且依赖 `python-docx` 对象的混合模块需要拆分为纯规则核心和来源适配器；相比直接引用外部目录，这些成本换取了离线部署、版本稳定、发布可审计和故障隔离。
