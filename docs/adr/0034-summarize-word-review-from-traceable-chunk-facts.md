# Word 全篇审查通过可追溯分片事实执行全局汇总

每个 Word 审查分片除局部问题外，还生成受限的摘要、关键定义、责任主体、时间数量范围、验收条件和跨章节核对项，并为这些中间信息分配可追溯标识。全局模型只接收文档标题结构、分片摘要、事实索引和压缩问题索引，用于发现跨章节矛盾、合并重复问题并形成总体结论；它不重新接收全文，无法引用输入标识的新增定位由 Adapter 拒绝。

将全文再次提交给汇总模型不适用于 40k 上下文和六万至十二万字文档；只做本地拼接则无法处理语义重复与远距离矛盾。受控事实索引增加了内部结果契约和验证逻辑，并且不能补救分片阶段没有识别的事实，但能在上下文预算内保持跨分片检查和问题定位可追溯。
