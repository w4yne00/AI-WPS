# 分离格式规则算法与权威模板值

已授权的 `wx-doc-format-skill` 同时包含可复用检测算法和面向其 WX 模板的硬编码标准，例如备用表正文字号、样式名和表格行高；这些值与 AI-WPS 当前《技术文件格式及书写要求》并不全部一致。决定 AI-WPS 当前选定的版本化模板规则是格式期望值的唯一权威来源，授权代码主要提供确定性识别和审计算法。算法中的模板名称、字体、字号、行高、缩进和样式默认值必须改为读取规则注册表，不能覆盖或补齐 AI-WPS 模板；模型也不得生成、推断或修改格式标准。

不依赖具体样式值的结构行为只有经过 AI-WPS 人工登记后才成为通用结构规则。模板未规定某项属性时返回“未配置格式规则”，不得套用第三方默认值，也不得判为合规或违规。每条问题必须记录规则标识、规则来源、模板版本和规则版本。该分离增加规则参数化与登记成本，但避免把另一套模板要求误报为公司标准，并使授权代码升级和模板变更能够独立审计。
