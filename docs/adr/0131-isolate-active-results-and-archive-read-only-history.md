# 按文档会话隔离活动结果并独立保存只读历史

三宿主不再把任务窗格中最后一次成功输出当作后续任务的隐式结果。活动任务及其进度、错误和结果按宿主、功能、文档会话隔离，每个功能和文档会话只允许一个未结束任务；本地校验通过并准备发送新请求时，旧结果立即退出活动区，失败时显示本次错误。切换设置、分页、预览、编辑填写项、选择写入目标、返回修改、复制或导出均不产生新任务，也不清除仍属当前任务的状态。该边界增加前端状态键和文档会话识别复杂度，但防止跨任务、跨功能和跨文档串用结果。

成功结果另存为用户主动读取的只读历史快照，失败和取消不归档。历史按功能展示同一 Adapter 运行环境中的结果，跨 WPS 与 Adapter 重启保留二十四小时，每功能最多二十条、单条最多 5 MiB、全局最多 100 MiB，并支持单条删除和清空该功能历史；清理超限记录时按完成时间删除最旧项。历史只保存成功输出及最小元数据，不保存原始输入、完整路径、密钥或完整请求。智能填写历史不得再次写回或重试，审查类历史只保存摘要和仍有效的专用报告入口。用户查看历史时，新任务完成只更新状态提示，不强制切回活动结果。
