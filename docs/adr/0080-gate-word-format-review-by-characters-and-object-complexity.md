# Word 格式审查同时按字符数和对象复杂度执行容量门禁

决定格式审查将六万及以下审查字符定义为标准文档，六万以上至十二万定义为大型文档，超过十二万首版明确拒绝且不截断。同时对内容块、表格单元格、格式区段、不支持对象数量和累计快照字节数设置独立安全上限；具体对象阈值必须由麒麟 WPS 真机基准确定、写入版本化配置并随发布披露，不能凭开发机数据形成产品承诺。任一维度超限时停止、清理暂存并返回超限维度、实际值和上限。

在验证范围内，确定性审查无需大型文档二次确认，也不依赖模型配置。模型语义补充使用独立调用预算，候选超过预算时将剩余对象标记为需要确认，不得缩减确定性报告。任务窗格持续显示阶段、对象数、批次和进度并允许取消。发布验收覆盖六万字标准样本、十二万字压力样本及字数较少但表格或格式区段极多的复杂样本。该策略避免将“十二万字”误解为任意对象复杂度都无上限支持。
