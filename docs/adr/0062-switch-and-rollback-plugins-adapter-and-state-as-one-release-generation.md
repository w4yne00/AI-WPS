# 插件、Adapter 和运行数据按同一发布代际切换回退

当前安装器先后覆盖三个插件、`publish.xml` 和 Adapter，跨多个目录无法由单个文件系统操作实现绝对原子切换，失败后可能留下新版插件与死亡 Adapter 的混合状态。决定把 Word、Excel、PPT 三个插件、`publish.xml`、Adapter 程序、自启动或当前版本指针及匹配的一致性运行数据快照定义为同一发布代际，整体验证、切换和回退。切换前必须确认 WPS、ET、WPP 已全部退出；所有候选文件先在隔离目录验证，切换过程写入持久化事务日志，各组件使用同文件系统临时目录和重命名逐项替换；最终健康检查失败或安装中断时，本次或下次安装依据事务日志反向补偿，恢复完整上一代际。禁止只回退 Adapter、插件或数据中的一部分并标记成功。该方案增加安装状态机、磁盘占用和中断恢复测试成本，但能够消除组件混装，并准确承认这是一项可恢复的补偿事务而非跨目录绝对原子操作。
