# 使用运行时总开关控制图像语义能力

决定 Adapter 本地管理端提供 `formatReview.imageSemantics.enabled` 全局运行时配置，新安装和从任何旧版本升级后均固定为 `false`，不得根据已有模型、图片模式或历史配置推断开启。开关只允许管理员在高级设置中操作；开启前必须确认指定目标 WPS 的图片导出验收已经完成。总开关启用后，各模型配置仍须单独选择图片输入模式、完成图片外发授权并通过与当前配置修订绑定的视觉能力验证，任一模型验证失效只使该配置降级，不自动修改总开关。开关变化只影响之后创建的格式审查执行基线，运行中任务继续使用提交时冻结的值。该运行时开关无需重新构建或重装交付包；关闭时任何任务均不得创建导出槽位、生成临时 PNG 或调用文档图片上传接口。
