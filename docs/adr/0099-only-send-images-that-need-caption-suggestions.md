# 只外发需要图题建议的图片

决定首版将“自动识别文档图片”拆分为本地盘点和受控外发两个阶段。WPS 与 Adapter 必须盘点格式审查承诺范围内的全部受支持图片，但只有同时满足以下条件的可关联图对象才能创建图片导出槽位并上传像素：确定性规则已经确认该对象缺少图题，当前配置的图片输入模式已通过视觉能力验证，并且在必需格式语义完成后仍获得可选格式语义调用预算。已有图题、题注关联未决、视觉能力不可用或预算不足的图片不得上传。候选按文档稳定顺序选择，不允许模型自行挑选；未入选原因进入结构化报告和语义增强诊断，且不得标记为 `pixel_inspected`。该决定保留自动生成缺失图题建议的目标，同时减少与任务无关的图片外发、磁盘暂存和模型调用；首版不提供全部图片内容审查。
