# 首版视觉识别只覆盖正文图片对象

决定首版自动导出并上传正文故事中由 WPS 明确类型确认的内嵌图片、浮动图片，以及能够安全取得实际像素的链接图片；同一段落中的多图仍组成一个图对象组，但每张图保留独立图片资产。图表、SmartArt、公式、OLE/ActiveX、文本框、自选图形、组合形状、页眉页脚和水印图片，以及无法安全导出的链接图片只盘点并披露，不进入视觉模型。对象处于 `InlineShapes` 或 `Shapes` 集合不能单独证明其为图片，导出失败时标记无法视觉审查，不得通过转换为内嵌形状、改变链接状态或其它文档修改取得像素。该范围覆盖常见截图和插图，同时延续首版对复杂 Word 对象的明确不支持边界。
