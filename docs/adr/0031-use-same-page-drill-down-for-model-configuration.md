# 模型配置采用同页下钻与服务端状态驱动

Word、Excel、PPT 的模型配置界面统一采用同页下钻结构：任务选项卡与紧凑配置列表、配置编辑、高级配置。完整表单不使用模态弹窗或列表内长折叠，返回时保留任务输入、排队状态和结果预览；未保存修改只在离开会丢失时确认。

配置完整度、默认激活项、最近验证摘要和名称唯一性由 Adapter 统一计算。任务窗格右上角只展示本地 Adapter 的自动健康状态，删除无业务价值的手动刷新按钮；断开时保留明确标注的只读快照并禁止副作用操作。该方案保持 Apple Design 所强调的稳定空间关系、即时反馈和克制动效，同时避免三个宿主形成不同状态判断。

模型配置允许分步保存为不完整状态，但不完整配置不能激活、验证或提交任务。API Key 通过独立维护层更换，已有密钥不回填前端。任务页只显示当前宿主、当前任务的完整配置，切换后立即持久化为该任务默认配置，且不影响已经排队或运行的任务快照。
