# Word 全篇审查只在认证指纹一致时跨重启续跑

Word 全篇审查持久化提交时的非敏感模型参数、模型配置标识、API Key 引用和不可公开的 Key 指纹，不在任务目录复制 API Key 明文。Adapter 重启恢复时重新读取引用的当前密钥并在内存中比较指纹，只有一致才继续使用已完成分片和原任务检查点；密钥被删除、轮换或引用失效时，旧任务不得改用新认证继续。

持久化 API Key 明文会扩大敏感凭据副本，只在重启后重新解析当前配置又可能让同一报告混用不同认证、路由或计费身份。引用加指纹会使 Key 轮换后的旧任务无法恢复，但保持了提交快照一致性，并允许管理员通过新任务明确采用新认证。
