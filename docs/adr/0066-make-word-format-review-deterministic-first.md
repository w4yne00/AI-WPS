# Word 格式审查以确定性规则为主体并限制模型权限

现有格式审查只抽取有限段落属性，并让模型辅助识别部分段落角色。决定将其重构为基于格式审查快照和格式语义模型的全篇只读审查：本地确定性规则负责所有能够由页面、内容块结构和格式事实验证的合规判断；模型只接收确定性规则无法可靠分类的模糊格式候选，用于补充段落角色、图表与题注等跨块语义关系，以及为缺失图题、表题生成只读建议。模型不得覆盖、放宽或反转确定性规则结论，不得修改快照或直接写回 Word。结果必须披露审查覆盖完整性、数据不足和不支持区域。

该边界允许复用已获作者授权的 `wx-doc-format-skill` 确定性规则思想和适配后的代码，同时保留 AI-WPS 对实时 WPS 文档、局部选区、Python 3.8 目标运行时和离线交付的控制。它增加格式语义模型、规则适配层和完整性校验的实现成本，但避免模型随机性成为格式合规依据，也避免在审查重构阶段引入批量自动排版风险。
