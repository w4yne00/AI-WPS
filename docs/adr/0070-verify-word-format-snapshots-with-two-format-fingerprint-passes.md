# 使用两遍格式指纹验证 Word 格式审查快照

格式审查依赖字体、缩进、题注关联等细粒度事实；用户在分批抽取期间仅修改格式，也可能使单遍结果混合多个文档状态，而 WPS 编辑序号不保证覆盖所有纯格式变化。决定第一遍按批上传完整格式事实，结束后再按相同范围执行第二遍轻量读取，只重新计算稳定对象顺序、文本摘要、结构关系、全部参与审查的规范化格式属性、覆盖统计及对应哈希。两遍结构指纹、格式指纹、对象数量或覆盖统计任一不一致，Adapter 不得提交快照，并清理暂存数据；批次边界的编辑信号只用于快速失败，不能替代第二遍校验。

第二遍不重复上传或保留完整文档数据，因此主要增加 WPS 对象读取时间，而不显著增加网络和前端内存。该成本换取格式报告对应单一可验证文档状态；快照提交后用户可以继续编辑，报告必须显示快照时间和指纹摘要，不得暗示结果对应当前实时文档。
