# 视觉关闭时继续执行确定性图片规则

决定 `formatReview.imageSemantics.enabled=false` 只禁止图片像素导出、暂存和外发，不关闭图对象盘点及确定性格式规则。默认关闭状态下，系统仍识别受支持图片，并检查缺少图题、题注位置和已配置格式要求；不得创建图片导出槽位、调用 `SaveAsPicture`、生成临时 PNG 或上传图片。若 Alt Text 和邻近文字为已确认缺图题的对象提供充分证据，模型仍可生成标记为 `text_evidence_only` 的只读图题建议；证据不足时返回 `not_assessable`，不得生成泛化标题。界面显示“图片视觉增强未启用”，不能显示为识图失败或模型不支持。结构化报告记录图片总数、缺题注数、文字证据建议数、无法判断数和实际上传数零；该状态只降低语义增强状态，不降低已经完整执行的确定性格式覆盖状态，也不阻止严格格式合规结论依据确定性问题形成。
