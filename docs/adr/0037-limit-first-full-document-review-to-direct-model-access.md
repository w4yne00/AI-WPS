# Word 首版全篇长文档审查只支持模型直连

Word 首版全篇长文档审查只对模型直连配置开放；工作流平台继续保留最多 12,000 字的限量单次审查。当前工作流平台中的 DeepSeek v4 flash 原生上下文为 1M，Dify 实际限制为 128k，模型节点的 `max token=2048` 是最大输出而非总上下文，因此这一范围差异不是因为工作流只能输入 2k。

模型直连由 Adapter 控制上下文预算、版本化系统提示词、分片事实索引、输出饱和信号和全局汇总契约。现有工作流平台使用自定义系统提示词，2,048 Token 输出更容易使问题列表饱和，且工作流封装未提供首版所需的分片中间契约和完整诊断。后续如扩展工作流平台全篇审查，应发布专用分片工作流并完成契约测试，而不是把现有 12,000 字应用直接表述为全篇能力。
