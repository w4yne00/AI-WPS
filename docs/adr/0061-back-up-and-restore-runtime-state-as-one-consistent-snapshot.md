# 运行数据按一致性快照整体备份和恢复

模型配置、八类任务映射、激活关系、API Key 文件和写作规范数据库之间存在引用关系，局部恢复可能产生配置存在但密钥或激活关系错位的状态。决定在每次安装、迁移和显式恢复前创建包含上述全部运行数据、版本、数量和校验清单的一致性快照；恢复只能在副本完成结构、引用关系和数据库完整性验证后整体原子切换，默认禁止只恢复某个 JSON、Key 文件或数据库。快照目录权限为 `0700`，敏感文件为 `0600`；至少保留最近三个已校验快照和上一已验收版本的最后有效快照，唯一有效或仍承担回退作用的快照不得因时间到期自动删除，清理必须确认已有新验证快照并生成不含 Key 明文的审计记录。该策略占用更多磁盘且减少局部操作灵活性，但运行数据规模较小，保持跨文件引用一致性和可靠回退优先级更高。
