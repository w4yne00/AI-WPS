# Word 全篇审查在分片之间让出共享运行槽

Word 全篇审查在同一文档内始终顺序调用模型，但每完成一个审查分片就持久化检查点并释放共享运行槽，再由协调器调度下一片。没有其他任务等待时立即继续；存在交互任务时沿用交互优先级和连续三次后让普通任务运行的公平规则。活跃全篇任务等待下一分片不占用八个新任务排队位置，全局一致性汇总也作为最后一个可调度执行片段。

让全篇任务从头到尾占住一个槽位实现更简单，但两个大型文档可以长期占满全部两个槽，使智能编写和智能仿写的交互优先级失效。分片级协作让出会延长全篇任务的墙钟时间并要求协调器区分首次排队与活跃任务续片，但不增加 Provider 并发量，也能复用每片已有的持久化恢复边界。
