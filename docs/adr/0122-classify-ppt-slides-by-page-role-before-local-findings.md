# 结构审查先判定幻灯片页角色再执行本地规则

当前结构审查没有页类型，本地规则把任何空主标题判为缺标题。目录页和结束页被正确抽成空标题后必然误报；智能总结的自由角色和提示词推断都不能进入这条判定。决定在合并本地发现之前，先为每一页赋予受控的幻灯片页角色：封面、目录、过渡、正文、结束。页角色用户可见，并决定缺标题、无标题信息不足、重复标题、标题过长和编号跳号是否对该页生效。

页角色由确定性证据确定，顺序为整套文稿中的位置与邻页关系、已抽取标题链、形状名。首版不读版式名，也不为区分过渡与正文去读取有标题页的正文。封面和结束只按整套页码识别，不得把本次审查页段的第一页或最后一页升格。过渡页只根据章节形态标题且后页为同编号子节认定。证据不足记为未确认页角色，按正文页执行规则，不得当作目录、过渡或结束来豁免。模型只能处理仍模糊的页，不得覆盖已确定角色，也不得单独改变规则豁免。

目录页和结束页豁免缺标题、无标题信息不足、重复标题和标题过长。封面页不豁免缺标题。过渡页不豁免缺标题和重复标题。编号跳号只作用于参与编号的过渡页和正文页。不采用「先改提示词认页类型」「复用智能总结 role」「有标题页抽正文再分过渡」「页段首页当封面」四条路径：前两条会把不可验证的生成结果写成规则输入，后两条分别破坏现有标题抽取合同和局部审查语义。
