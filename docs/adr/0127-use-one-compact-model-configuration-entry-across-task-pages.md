# 三宿主任务页使用统一的紧凑模型配置入口

决定将 Word、Excel 和 PPT 九类模型任务页现有的“标签 + 原生下拉框 + 当前配置状态”改为标题区单行入口，固定显示为`状态标记 配置名称 · 接入方式 ›`，接入方式只使用“工作流平台”或“模型直连”。点击入口打开锚定式配置列表，选择后立即激活并保留忙碌门禁和失败回滚，列表末尾提供“管理配置”；模型标识、API 地址、Key 状态、备注和完整度仍不进入任务页，完整设置页及任务特有的配置就绪提示保持不变。

该决定取代 ADR-0112 对原生 `select` 控件的限定，同时保留其最小信息披露规则。三宿主必须同步采用同一交互合同，避免只为智能填写建立特殊入口；各宿主可以保留自身强调色和独立实现，但必须共享显示格式、键盘行为、焦点恢复、加载与失败状态及契约测试。Excel 三类任务页先落地该入口，Word 与 PPT 分别按 #150、#151 迁移。
