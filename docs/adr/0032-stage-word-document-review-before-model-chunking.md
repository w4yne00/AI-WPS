# Word 全篇审查先分批暂存再由 Adapter 生成模型分片

Word 全篇审查由 WPS 前端分批、轻量地抽取带稳定原文定位的正文，并暂存到本地 Adapter；Adapter 验证批次连续性与审查覆盖完整性后，再根据当前模型输入预算生成审查分片、调用模型并汇总结果。一次用户操作可以包含多次本地暂存请求和多次模型调用，但不得把部分抽取或部分模型结果表述为全篇审查完成。

不采用 WPS 一次同步读取并提交全文，以避免长文档阻塞任务窗格并支持抽取进度、取消和失败恢复；也不由 WPS 直接生成模型分片，以免插件绑定模型上下文、写作规范长度和重叠策略。该边界增加了暂存接口、临时数据清理和完整性校验，但将 WPS 对象读取与模型编排职责分离。
