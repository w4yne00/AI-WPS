# 限制单个格式审查图片的资源占用

决定首版对 WPS `SaveAsPicture` 导出的每张临时 PNG 同时执行三项阻断式门禁：文件大小不超过 `5 MiB`，宽和高任一单边不超过 `8192` 像素，总像素不超过 `2000 万`。Adapter 在图片进入模型传输链路前读取并校验这些事实；任一维度超限时不得上传图片，也不得静默跳过、在 Adapter 内缩放或重新压缩。若对象仍有 Alt Text 或邻近文字，相关建议只能标记为 `text_evidence_only`；没有足够文字证据时标记为 `not_assessable`。结构化报告记录超限类型和实际值，但不保留图片内容。这组阈值用于限制 PNG 导出后的磁盘与内存占用、Base64 编码膨胀和不同模型接口的输入差异；发布前仍须通过麒麟 WPS 12.1.2 及正式模型接入路径压测，若验证需要调整则必须版本化变更门禁，不能在运行时静默放宽。
