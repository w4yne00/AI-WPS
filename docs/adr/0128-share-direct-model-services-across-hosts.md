# 三宿主共享直连服务配置，任务独立选择模型

AI-WPS 不再把两种模型调用方式都封装为按任务隔离的完整配置。工作流平台继续由每个功能独立维护配置；模型直连则在同一本地 Adapter 运行环境中只保存一份服务地址和 API Key，并允许 Word、Excel、PPT 全部功能共享选择该直连服务。每个功能仍独立保存模型标识及温度、Token、图片能力等任务参数，任务提交时冻结服务、认证指纹和任务选择快照。该决定取代 ADR-0019；它减少重复录入并维持任务能力差异，代价是需要迁移既有重复直连配置，并保证共享服务的修改、删除和密钥轮换不会静默改变已排队或运行任务。

同一运行环境最多保存五份共享直连服务配置。每份服务保存一个默认模型，尚未单独设置的功能继承该默认值，之后可以按功能覆盖。可用模型优先由 Adapter 使用服务地址和单份 API Key 自动读取，并以下拉菜单提供选择；保存或更换地址、Key 时立即刷新，也允许手动刷新，最近一次成功列表缓存二十四小时并显示获取时间。刷新失败时可以使用未过期缓存；已选模型从新列表消失后阻断新任务，不得静默切换。为兼容未实现模型列表接口的 OpenAI-compatible 服务，读取失败时保留明确标记的高级手动模型标识入口；手填值只有在验证调用成功后才能视为已验证可用。

三宿主设置首页都提供同一个“直连服务”入口；各功能页只维护任务独占的工作流配置和任务模型选择。被任务引用的共享服务不得直接删除，界面必须列出引用功能并要求先改绑；修改服务地址前也必须披露受影响功能。升级合并后若不同任务保留不同模型，不猜测默认模型，现有任务继续使用原绑定，新功能首次使用前由管理员补选服务默认模型。
