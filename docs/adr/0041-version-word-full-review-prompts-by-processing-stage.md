# Word 全篇审查按处理阶段维护独立版本化提示词

模型直连的 Word 全篇审查分别使用版本化的分片审查 System Prompt 和全局一致性汇总 System Prompt，两份资产独立记录版本与 SHA-256、随交付包发布，但共用同一个 `word.document_review` 模型配置和认证快照，不形成两个用户可见任务。只有一个有效分片时直接形成最终结果，不执行全局汇总调用；两个及以上分片才调用汇总提示词。

分片阶段需要返回原文锚点、局部问题、受控摘要和事实索引，全局阶段只能消费这些索引并引用既有标识，两者职责和输出契约不同。共用一份提示词会混淆局部与全局事实边界；对单分片文档无条件增加汇总又会产生没有必要的等待和费用。
