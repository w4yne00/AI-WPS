# Word 全篇审查按用户动作区分任务与重试

用户每次主动发起全篇审查都使用新的 `clientJobId`，即使正文、要求和配置相同，也重新执行。一次提交的网络重试沿用原 `clientJobId` 和快照；任务已结束并清理快照后，通过原任务编号查询状态和结果，不重新提交旧快照。同一任务不得跨文档会话或宿主复用；当前文档已有运行任务时，仍保留原有忙碌保护。

快照内容、文档类型、审查重点、写作规范、模型配置、System Prompt 和分片策略继续用于任务恢复校验。只有未提供 `clientJobId` 的旧调用保留按输入身份复用排队、运行或可恢复失败任务的行为；显式新任务编号不会返回旧失败任务。界面重开和网络恢复应查询原任务，不能把相同输入当成用户要求复用历史结果的依据。本决策按 Issue #253 更新，不改变快照清理和报告保留周期。
