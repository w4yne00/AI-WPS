# Word 全篇审查按输入身份复用相同活跃任务

Word 全篇审查使用快照完整哈希、文档类型、审查重点、写作规范快照、模型配置、System Prompt版本和分片策略版本生成任务身份。身份相同的等待确认、排队、运行或可恢复失败任务直接返回原任务号；二十四小时内已有相同完成报告时先提示查看，只有用户明确选择重新审查才创建新任务。快照哈希不同始终视为新的文档版本。

现有 `clientJobId` 只能防止一次提交响应丢失后的重复请求，不能阻止双击、任务窗格重开或多个 WPS 窗口为同一输入创建多个模型任务。内容与处理配置共同参与身份计算，会使配置或规范变化后的相同正文产生新任务，但这正是避免把不同审查条件误认为同一结果所需的边界。
