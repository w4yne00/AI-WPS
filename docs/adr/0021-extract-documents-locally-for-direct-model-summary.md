# 模型直连的 PPT 文档总结使用本地文档抽取

模型直连不适配厂商专有文件上传 API。对于 PPT 文档总结，Adapter 在目标机内只读解析 Markdown 和 DOCX，并把受限的结构化文本放入一次 OpenAI-compatible Chat Completions 请求；原始文件不上传到模型厂商的文件服务，工作流平台则继续沿用既有 `/files/upload` 契约。

这一选择让两种模型调用方式都保留文档总结能力，并避免引入新的云端文件协议和依赖。代价是 Adapter 必须独立承担文档解析、输入预算、截断披露和恶意 DOCX 防护，且模型直连只能理解可抽取文本，不能读取图片、嵌入对象或复杂版式。
