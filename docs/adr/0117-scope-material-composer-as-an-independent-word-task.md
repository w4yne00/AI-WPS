# 素材编排作为独立 Word 任务，与当前文档解耦

素材编排以用户本机选择的一份素材和一条自由指令为输入，产出方案大纲分工、方案编制、会议纪要、工作总结和运行月报等材料。它不复用 `word.smart_write`，而是登记为独立任务 `word.material_composer`，拥有自己的模型配置、API Key 引用和版本化任务系统提示词。

复用既有写作任务会让两个输入形态和输出契约都不同的功能共享密钥与提示词，违反按任务配置模型接入且不跨配置回退的既有约定。独立任务标识由 `host_for_task` 的前缀推导自然支持，无需改动宿主映射。

首版边界明确收窄，以保证调用次数、失败状态和结果覆盖范围可预测：

- **单素材**。对外接口以数组形态承载素材令牌，首版长度限一，为后续多素材综合预留扩展位而不改契约。
- **不附带当前文档**。当前宿主打开的文档不作为上下文送入，避免用户无法判断模型依据的内容，也避免挤占模型输入预算；需要基于当前文档写作时使用既有写作任务。
- **单轮**。界面可呈现为对话形式，但每次提交都是一次独立请求，不维护会话标识与上下文累积。
- **只读落地**。结果提供预览、复制和插入到光标处，不执行全文替换。素材与当前文档没有内容对应关系，全文替换语义不明且不可逆。
- **超预算即拒绝**。沿用既有约定，不截断、不抽样、不自动分块；并在抽取完成后立即执行提交前预检，不让用户等待长任务超时才被拒绝。

输出容量沿用既有默认预留，不为本任务单独抬高，篇幅要求通过任务系统提示词约束；确有更长输出需求时由用户在该任务的模型配置中自行调整。
