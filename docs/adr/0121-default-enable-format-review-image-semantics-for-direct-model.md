# 格式审查模型直连默认开启图像语义补充

决定从当前源码起，Word 格式审查在模型直连下默认尝试为图片外发候选导出并发送像素，不再把图像语义当作产品默认关闭的休眠能力。能力边界仍是缺图题的图像语义补充，不是图片内容审查或 OCR；工作流平台保持默认禁用。

本决策取代 ADR-0108 的产品默认关闭、ADR-0109 中「新装和升级固定为 false」以及必须先确认 WPS 导出验收才能开总开关的要求，也取代 ADR-0104 中「图片输入模式默认 disabled、必须单独点允许外发、任务页可本次关闭」。ADR-0094 的视觉能力验证、ADR-0099 的「只发缺图题候选」、ADR-0110 的确定性图片规则、以及 PNG 槽位/门禁约束仍然有效。

总开关留下作为默认开启的运维止损；关闭则全机不建槽、不导出、不外发。格式审查直连配置默认 `openai_image_url`，仍允许改回 `disabled`。管理员保存可用直连配置即写入外发绑定（主机 / 模式 / 模型标识），变化即失效；须再次保存后重新绑定。探针未通过或 `SaveAsPicture` 失败只导致视觉关闭降级，不阻止确定性格式审查。Issue #59 的目标机验收仍是独立结论，不得用产品默认开启冒充已验收。覆盖升级迁移由后续 Issue 单独处理。
