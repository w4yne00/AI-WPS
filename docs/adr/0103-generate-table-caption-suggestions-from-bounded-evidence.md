# 使用受控文本证据生成缺失表题建议

决定首版只对确定性规则已确认属于数据表且缺少表题的对象请求模型建议，不将表格渲染为图片。模型输入使用版本化表题证据视图：完整多级表头和合并单元格关系、行列数、单位、来源、表下注、所在标题及紧邻上下文必须提供；全部可见单元格能够放入格式语义输入预算时一并提供，否则只提供明确标记为抽样的首三行和末两行。模型响应必须声明证据视图为完整或受限，不能把样例描述为整表。建议不得引入输入证据中没有出现的机构名、时间、地域、数值或统计口径，违反结构或内容约束时拒绝整条建议；证据不足时只返回无法可靠建议，不得生成泛化标题。该受限证据视图是预先定义且显式披露的候选输入类型，不属于对超限完整候选的静默截断。所有表题仍为只读建议，不构成原文事实或自动写回。
