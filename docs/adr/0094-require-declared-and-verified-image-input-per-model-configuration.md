# 每个模型配置必须声明并验证图片输入能力

决定格式审查模型配置新增图片输入模式，首版为 `disabled`、`openai_image_url` 和 `dify_file`，默认禁用且不得根据 GLM、Qwen、代理模型名称或厂商自动猜测。启用或修改后，系统使用内置无敏感测试图片执行严格识别探针，只有模型返回可验证图片内容且响应通过 Schema 才视为视觉能力有效；结果绑定配置修订、服务地址、接入方式和模型标识，任一变化即失效。有效配置在正式审查中自动发送图片，失败或过期配置降级为仅使用 Alt Text 与邻近文字，证据不足时无法判断；单张图片上传失败只降级该图，不使确定性审查失败。只有 Adapter 确实发送图片且验证仍有效时，报告才能标记 `pixel_inspected`。该显式协议增加配置和验证步骤，但兼容任意视觉后台并防止文本模型因接收到不支持的载荷而拖垮整个任务或伪造看图结果。
