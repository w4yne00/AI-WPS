# 将题注关联与题注位置合规分开判断

决定每张表形成一个可关联对象，同一段落内的一个或多个内嵌图片形成一个图对象组，首版一个对象只允许一个主题注。系统只在同一节、同一正文故事范围内建立有限候选边，不跨标题、正文段落、其它图表或节边界任意搜索；唯一且类型兼容的候选由确定性规则关联，多候选、重复或非相邻情况才允许模型从给定候选边中选择或返回无法确认。题注是否关联与位置是否符合“表上图下”分别判断，因此表题位于表下或图题位于图上仍认定题注存在并报告位置违规，不再重复生成缺题注；关联仍歧义时，题注报告孤立或待关联，对象的缺题注状态为无法判定。复杂子图独立题注和共享总题首版只盘点，授权代码中的移动、重排和自动插入逻辑不进入只读审查。该关系模型减少重复误报，并保持未来逐项修复所需的独立问题边界。
