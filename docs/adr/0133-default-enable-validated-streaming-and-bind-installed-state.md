# 默认开启已验证模型的直连流式并由安装代际自动绑定共享状态

决定从当前源码起默认开启 Word 智能编写与智能仿写的模型直连流式总开关；`AI_WPS_ENABLE_DIRECT_STREAMING=0` 继续作为即时运维回滚。默认开启不绕过模型能力门禁，只有当前服务修订、API Key 指纹和精确模型标识的 `streamingCapability` 为 `validated` 时才发送流式请求；未验证或不支持的模型继续使用阻塞路径。本决策取代 ADR-0132 中“必须显式设为 1 才启用”的首候选策略，不改变增量预览只读、取消、降级和资源上限合同，也不把默认开启等同于目标机性能验收通过。

安装根下的 `current` 始终指向 `releases/<版本>`，配置、模型/工作流 Key、规范库、历史和备份属于安装根共享状态，不属于某个 release。Python 运行时和 Shell 启动脚本在未显式提供路径变量时，必须通过 `current` 与实际 release 的绑定自动解析到同一 `state/backups/var`；若执行的 release 不是当前代际，则不得自动接入共享状态。该约束避免手工重启、systemd 重启或版本切换后回退读取 release 内空配置，同时保留显式绝对路径作为最高优先级。
