# 明确首版 Word 格式审查覆盖范围并披露未检查对象

决定首版全篇格式审查全量处理页面与节属性、正文段落及字符格式、标题、列表、正文表格、图与表题、目录、注和附录；页眉页脚正文及页码采用尽力读取，读取失败时返回数据不足。文本框、形状、SmartArt、公式内部、脚注尾注、批注、修订历史、隐藏文字和图片文字首版只记录类型、数量和读取状态，不承诺内部格式审查。每个支持对象必须标记已检查、无需检查、数据不足或不支持，结果同时展示覆盖完整性和不支持对象清单。

该范围显著扩大现有只读取前八十段和少量段落属性的能力，并覆盖授权规则中可适配到实时 WPS 语义模型的标题、列表、表格、题注、目录、注和附录审计。它不能被描述为检查了 DOCX 的所有对象，但通过明确披露未检查区域，避免把接口不可读或未实现对象误报为格式合规；后续扩展某类对象时必须同步更新抽取契约、规则、测试和覆盖说明。
