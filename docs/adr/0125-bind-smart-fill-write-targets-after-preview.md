# 智能填写在预览后绑定写入目标

决定将 `v0.26.0` 智能填写从“先冻结目标、再读取同行来源并生成”改为“先冻结来源和填写意图、逐来源数据行生成预览、再由用户鼠标选择写入目标”。来源必须是包含一行表头的连续矩形区域，填写意图必填；每个可见数据行形成一个不带地址的填写项。预览形成后，用户在来源所在工作表选择不与来源重叠的连续单列目标区域，目标数量必须等于全部预览项数量并按从上到下一一映射，被排除、失败或未完成的项目保留空位。

该决定取代此前“模型结果绑定提交前冻结目标 ID”的设计，但保留受控写回边界：模型不能决定地址或生成公式，空白目标可直接写入，已有普通文本或数值需要一次批量确认，公式、合并、隐藏和受保护目标始终拒绝；点击写入时重新读取并冻结当前选区，执行来源与目标预检，写入中途失败必须补偿恢复，成功后同一预览不得再次提交。这样牺牲了依据目标列标题自动猜测意图的少量便捷性，换取更直接的来源—预览—落点流程和更少的范围控件。

来源先行生成（Issue #144）只交付冻结来源与无地址预览；目标映射和写入入口仍由后续票（#148）开放。在目标映射完成前，正式任务页不得出现可用的“写入内容”入口。
