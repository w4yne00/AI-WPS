# 定位格式问题前验证快照锚点

决定每个格式问题实例提供只读“定位到文档”能力，但不得仅按快照中的旧段落号跳转。任务窗格先确认当前文档身份，再以原始 WPS Range、对象类型、文本指纹和相邻结构验证位置；原位置偏移时只允许在有限邻域找到唯一匹配后重定位。找不到或存在多个候选时将锚点标记为失效并拒绝跳转，提示文档已经变化。

重复问题组可以逐项查看下一处，但每次仍独立验证，不能借此执行批量写回。该能力要求格式快照记录 Range 起止位置、内容块标识、文本指纹和相邻块摘要，报告保留相应校验信息。失效时拒绝定位会降低编辑后旧报告的便利性，但避免把用户带到错误段落、单元格或图表对象，并为未来受控逐条修复建立可信前置条件。
