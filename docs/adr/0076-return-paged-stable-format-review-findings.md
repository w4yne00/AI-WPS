# 格式审查返回分页稳定问题实例和重复问题组

现有格式问题只使用段落号和字符串形式的当前值、期望值，无法稳定定位表格、字符区段和图表对象，也无法承载规则来源、覆盖状态或大量重复问题。决定每个格式问题实例以规则标识、稳定格式锚点和属性路径形成稳定身份，并记录结构化当前值与期望值、单位、容差、分类、严重级别、对象角色、确定性证据、数据读取状态、建议、规则与模板版本，以及模型语义来源和置信度。展示文案和数组下标不参与问题身份。

相同规则和问题特征可以形成格式重复问题组用于概览和统计，但不得合并删除各位置的问题实例。接口分页返回实例，报告同时提供多维结果状态、覆盖清单、未执行规则、数据不足、不支持对象和语义增强诊断。任务窗格直接渲染结构化数据，Markdown 由结构化报告生成且只用于复制或导出。该契约增加结果模型复杂度，但支持数千问题、可靠定位、版本追溯和后续逐条修复扩展。
