# 在发布前编译并审定格式规则包

当前格式模板 JSON 由人工维护，不能证明与源 DOCX 持续一致，也无法仅靠样式值表达标题层级、题注位置和列表连续性等结构约束。决定以权威模板 DOCX 和人工审定的结构规则清单为输入，在构建期编译版本化格式规则包；从 DOCX 提取页面、节、样式、字体、字号、间距和缩进等可验证值，从清单加载标题、列表、目录、表格、题注、注和附录结构规则。规则包同时记录模板 ID、版本、源 DOCX SHA-256、单位、容差、规则来源、严重级别、适用对象、启用状态、授权算法版本和本地适配版本。

Adapter 运行时只读加载已经校验的规则包，目标机不动态解析模板 DOCX。模板、结构规则或授权算法发生变化时，构建必须生成规则包差异报告；存在未确认差异、来源缺失、值冲突或解析失败时阻止发布。该流程增加模板更新审核步骤，但避免运行时漂移，并使每条格式结论能够追溯到明确标准和算法版本。
