# 恢复构建前端只开放非破坏性恢复入口

决定 `v0.23.1-alpha` 在 `degraded` 状态下保持模型配置等正常子系统可用，写作规范管理只读，Word 任务按规范降级继续并在提交前和结果区明确提示，同时允许重新检测和导出脱敏诊断；在 `recovery` 状态下，前端显示 Adapter 已连接、故障子系统、发生阶段和最近有效备份状态，只允许重新检测、创建只读备份和导出脱敏诊断，禁止配置新建、修改、激活及模型任务提交。恢复构建不提供一键重置或一键恢复备份，真实数据恢复必须通过指定已校验备份 ID、要求二次确认并生成审计记录的显式命令完成。图形化恢复最早在目标机验证稳定后纳入 `v0.24.0-alpha`。该边界牺牲部分现场操作便利性，但避免尚未经验证的 UI 恢复流程覆盖唯一运行数据或把空数据误当成修复结果。
