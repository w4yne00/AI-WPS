# 图片审查随包休眠交付且不阻塞当前发布

决定在内网测试条件不足期间，WPS `SaveAsPicture` 图片导出和图像语义补充代码可以随整合版本交付，但产品总开关和所有模型配置的图片输入模式均默认为关闭。关闭状态下不得创建图片导出槽位、生成临时 PNG、调用图片上传接口或将对象标记为 `pixel_inspected`；确定性格式审查、文本语义补充、表题建议和 Adapter 升级修复不受影响。当前整合版本取消以麒麟 WPS 12.1.2 全量图片样本验收作为发布阻断条件，因此不得在版本说明或界面中宣称图片审查已经可用。

后续具备测试条件后，必须先在指定目标 WPS 环境完成内嵌与浮动图片、透明背景、裁剪旋转、同段多图、资源边界、异常清理和文档不变性等验收并留下版本化记录；随后管理员还需完成图片外发授权和当前模型配置的视觉能力验证，才允许显式开启。验收失败时保持关闭，不影响其它格式审查能力。该决定取代 ADR 0096 中“图片导出真机门禁必须阻断整合版本发布”的要求，但不放宽 ADR 0096 至 ADR 0107 定义的运行时安全、证据和数据外发约束。
