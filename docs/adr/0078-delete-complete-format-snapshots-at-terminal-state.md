# 格式审查任务终态立即删除完整快照

决定未提交的格式快照会话默认十分钟过期，已提交快照只在确定性审计和必要模型语义补充运行期间保留；任务完成、失败或取消后立即删除完整文本、完整格式块和模型候选上下文。最终分页结构化报告本地保留二十四小时，只保存问题实例、必要证据短片段、锚点校验信息、统计和脱敏诊断，用户可以主动删除或导出 Markdown/JSON。Adapter 启动和定时清理过期、孤立暂存数据。

模型只接收模糊候选的最小上下文，不上传原始 DOCX。日志、最近任务诊断和模型调试记录不得包含正文、题注建议全文、API Key 或完整格式快照。该策略使旧报告仍可查看和定位，但不为报告保留而长期保存整篇文档格式事实，降低本地敏感数据暴露和磁盘残留风险。
