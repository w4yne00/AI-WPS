# 分别报告格式审查执行、合规、覆盖和语义增强状态

现有格式审查主要返回问题数量，无法区分任务是否成功、承诺范围是否完整、规则是否因数据不足跳过，以及模型语义补充是否降级，容易将“零个问题”误解为格式合规。决定结果分别报告执行状态 `completed/failed/cancelled`、合规状态 `passed/violations_found/not_assessable`、覆盖状态 `complete/partial` 和语义增强状态 `not_needed/completed/degraded`。

只有执行完成、承诺范围覆盖完整、全部必需规则已执行、没有未解决模糊角色且没有格式违规时才显示“格式审查通过”。已经盘点并披露的首版不支持对象不使承诺范围自动变为部分；承诺范围内对象读取失败必须标记部分。已发现违规同时覆盖不完整时，界面既展示问题，也明确仍有未完成区域。该多维状态增加结果模型和展示逻辑，但消除任务成功、零问题、覆盖完整和合规通过之间的错误等同。
