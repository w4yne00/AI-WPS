# 保留后台任务协议并为交互文本提供增量预览

AI-WPS 的模型性能优化继续以后台模型任务作为提交、恢复、取消和终态结果的权威边界，不把任务提交改成长连接，也不让 WPS 任务窗格直接连接模型服务。Adapter 先为全部模型任务补齐毫秒级阶段观测并分块执行高成本 WPS 抽取，再从模型直连的智能编写和智能仿写开始接收上游流式响应；任务窗格通过带单调序号的长轮询增量事件获得文本，原有任务状态查询继续作为恢复和兼容兜底。工作流平台首期保持阻塞调用，结构化任务只公开真实阶段和终态校验后的完整结果，不展示残缺 JSON。

用户停止交互文本生成时，Adapter 应终止当前上游响应并将任务结束为已取消。已经收到的文本只形成可查看、可复制的增量文本预览，不进入历史、不能写回文档，也不能冒充成功任务结果；不支持流式或可靠取消的服务继续使用阻塞任务语义并如实披露。该选择保留现有幂等提交、文档会话隔离、重开续查和双 Adapter 运行时兼容，同时接受首期只覆盖少量自然文本任务、需要维护增量事件序号与有界缓存的成本。

增量文本预览只在 Adapter 内存中随现有任务保留期存在，任务窗格重开后可以按任务号和事件序号恢复，但不写入磁盘。流式能力通过任务验证按服务修订和精确模型标识确认；只有在尚未收到任何正文增量时遇到明确的不支持响应，才允许回退一次阻塞调用，收到正文后断线不得自动重复调用。正式内容必须过滤推理字段、工具调用、心跳以及跨增量边界的 think 内容。

首个候选版只修改 `formal-plugin-kit`，并由 `AI_WPS_ENABLE_DIRECT_STREAMING=1` 显式开启；旧 `wps-addon` 原型不进入本轮改造。上线前在麒麟 V10、WPS 12.1.2 上记录点击反馈、模型首个可见内容、首渲染、取消确认和运行槽释放等毫秒级脱敏指标，不新增远程遥测或磁盘时序库。Excel 智能填写、Word 全篇审查和格式审查的高成本 WPS 读取必须分片让出事件循环并允许片段间取消，单片目标不超过五十毫秒，可以接受总抽取耗时最多增加百分之十。

智能编写和智能仿写分别在既有任务路径下提供长轮询增量事件接口，客户端提交 `afterSequence` 和最长二十五秒的等待时间。正常响应返回连续增量；首次连接或事件缺口同时返回当前完整预览快照和最新序号，使任务窗格可以重置后继续。Adapter 将上游碎片按最长五十毫秒或累计四 KiB 合并发布，单任务增量预览最多五百一十二 KiB、事件环最多二百五十六项，完整模型响应最多五 MiB；达到增量预览上限后停止发布正文增量并明确披露，但继续等待受控终态。

生成中的增量预览只使用纯文本和生成状态，终态完成后才执行受限 Markdown、对照和本地写作检查。用户切换模式、文档或历史不会停止后台任务，增量只更新其所属文档会话和功能；用户主动离开底部后不强制自动滚动。增量接口不可用或连续三次查询失败时，任务窗格退回现有三秒状态轮询，不终止任务，也不根据版本号猜测能力。

任务终态采用先提交者获胜：取消先被 Adapter 接受时结束为已取消，完整结果先提交时保持已完成。收到部分正文后的网络或模型错误结束为失败，部分文本在现有终态任务保留期内仍可查看和复制，但不自动重试、不归档、不写回；用户重新生成必须提交新任务。
