# 现有工作流档案原地迁移为模型配置

升级后的 Adapter 对现有工作流档案执行一次幂等迁移：保持配置 ID、任务归属、名称、备注、API Key 引用和激活状态，将升级前统一 API URL 复制进每个配置，并把模型调用方式设为工作流平台。API Key 文件不移动或重写，安装程序继续保护现有配置和运行数据。

旧配置字段至少保留一个版本供旧版回滚读取，但新模型配置不反向同步旧结构。这样正常升级不要求用户重新录入 URL 或 Key，同时避免新运行时长期保留全局 URL 继承和档案自包含两套配置来源；代价是回滚旧版本只能恢复使用升级前已有的平台配置，无法识别升级后新建的模型直连配置。
