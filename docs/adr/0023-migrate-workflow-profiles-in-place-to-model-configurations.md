# 现有工作流档案原地迁移为模型配置

升级后的 Adapter 对现有工作流档案执行一次幂等迁移：保持配置 ID、任务归属、名称、备注、API Key 引用和激活状态，将升级前统一 API URL 复制进每个配置，并把模型调用方式设为工作流平台。成功迁移后写入版本化完成标记；后续读取不得再次把旧字段作为补写来源。API Key 文件不移动或重写，安装程序继续保护现有配置和运行数据。

旧配置字段至少保留一个版本供整体快照回滚读取，但新模型配置不反向同步旧结构。迁移模型配置一旦在新运行时删除，重启和再次覆盖安装均不得从旧字段恢复；只有管理员主动恢复升级前整体快照时才随旧状态恢复。这样正常升级不要求用户重新录入 URL 或 Key，同时避免新运行时长期保留全局 URL 继承和档案自包含两套配置来源；代价是仅回滚程序而不恢复整份旧状态时，已删除配置的旧密钥引用不保证可用。
