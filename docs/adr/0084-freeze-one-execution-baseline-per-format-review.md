# 每次格式审查冻结一个执行基线

决定格式审查提交任务时冻结配置 ID 与修订、接入方式、服务地址、精确模型标识、上下文和输出容量、温度等接入参数，以及 System Prompt、格式规则包和格式模型能力表的版本与哈希；API Key 解析到任务进程内存中的认证快照，不额外落盘或进入报告、日志和诊断。同一任务的全部批次始终使用该执行基线，用户在运行期间切换、修改或删除配置只影响后续任务；报告仅记录可安全披露的标识、修订和哈希。该选择意味着本地删除配置不能立即撤回已经启动任务持有的凭据，要求立即失效时仍需在模型服务端撤销 Key，但避免一次报告混用新旧模型、提示词或规则版本而失去可重复性和审计意义。
