# 格式审查豁免可靠识别的 Word 目录区域

决定让 Word 格式审查只识别目录边界而不审查目录格式：WPS 自动目录结构，或由目录标题、连续条目、点引导符、尾部页码和目录样式等多项相互独立确定性强证据确认的完整目录区域，不产生格式问题，并在覆盖摘要中披露已略过的区域及段落数量。模型判断只能作为辅助证据，不能单独建立豁免区。

**当前实现范围（PR #155）**：仅覆盖 WPS `TablesOfContents` 集合和 `Fields` 中 `wdFieldTOC` (Type=13) 字段标识的自动目录区域。

**后续实现范围（Issue #149）**：手工强证据目录（多项确定性证据确认但无 WPS API 自动标识）和疑似目录（证据不足的连续内容）的识别与处理。

证据不足的连续内容标记为疑似目录，不按正文产生格式问题，也不视为已审查或已豁免；报告必须说明无法判定并把格式覆盖状态置为部分。该选择有意用可见的不确定状态替代目录误报，同时避免把模型猜测或单一“目录”关键词变成静默审查盲区。
