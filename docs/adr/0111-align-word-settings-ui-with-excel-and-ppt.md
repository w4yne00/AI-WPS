# Word 设置页对齐 Excel 和 PPT 的紧凑界面基线

决定在不改变 Word 设置能力和数据契约的前提下，重排 Word 设置页，使其结构、按钮几何和交互状态与现有 Excel/PPT 设置页保持一致。统一结构为顶部状态条、模型接口卡、宿主任务选项卡、配置列表主页、独立配置编辑子页和默认折叠的高级诊断；Word 专属写作规范库继续作为独立设置卡保留。普通控件采用 36 像素基线高度、6 像素控件圆角、8 像素面板圆角，列表小按钮不低于 32 像素；主按钮、次按钮、危险按钮、选中标签、高亮、悬停、按下、键盘焦点、禁用和窄任务窗格折行均使用与 Excel/PPT 相同的状态模式。Word 继续使用自身宿主强调色，不复制 Excel 绿色或 PPT 强调色。重构不得改变配置保存、激活、验证、删除、恢复模式、写作规范和诊断行为，并须以三宿主结构契约和窄窗视觉回归验证统一性。
