# 按需逐组导出格式审查图片

决定首版不在格式快照阶段预先导出或暂存全部图片。完成确定性规则和必需格式语义调用后，Adapter 根据实际剩余调用预算按文档稳定顺序选定图片外发候选，并且每次只为一个原子图像语义批次分配导出槽位。WPS 校验当前文档仍对应原格式快照后，将当前组通过 `SaveAsPicture` 导出；Adapter 完成该组模型调用及必要重试或纠正后立即删除 PNG，随后才处理下一组。这样正常运行时临时 PNG 的驻留范围不超过一个图对象组，也不会导出最终没有调用预算的图片。图片增强阶段要求原 WPS 文档和任务窗格保持可用；用户关闭文档、退出 WPS、前端响应中断或快照校验失败时，不使已经完成的确定性格式审查失败，未导出的图对象组改为 `text_evidence_only` 或 `not_assessable`，语义增强状态标记部分完成。异常残留最晚在任务完成、失败、取消或会话超时时清理。
