# Word 全篇审查快照受控临时落盘并支持续跑

Word 全篇审查将冻结后的正文快照、分片清单、任务检查点和已完成分片结果受控暂存到本机，以便 WPS 关闭或 Adapter 重启后从最近检查点继续。暂存目录使用随机任务标识且不包含原文件名，文件权限固定为 `0600`，保存内容必须带完整性校验，不保存 API Key，也不得通过诊断接口披露正文。

仅使用内存可以减少正文落盘，但会使包含多次模型调用的日常全篇任务在进程中断后整篇重跑，重复产生等待和模型费用。受控落盘增加了敏感正文的本地留存风险，因此完成、取消和不可恢复错误立即删除正文快照；可恢复失败或中断任务从停止运行时起保留两小时，运行时间本身不计入恢复期。过期、损坏或无法验证的数据由 Adapter 启动扫描和周期清理删除。

正常完成后，全文快照、分片中间结果和事实索引立即删除；只包含摘要、覆盖状态、问题必要原文片段、建议、锚点、处理状态和统计信息的最终结构化报告保留二十四小时，供分页查看、恢复处理或导出。用户可以主动删除报告，过期后不得返回空报告冒充仍可查看的结果。
