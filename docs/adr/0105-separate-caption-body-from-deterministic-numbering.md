# 模型只生成题注正文

决定首版 `suggest_figure_caption` 和 `suggest_table_caption` 只允许模型返回题注正文，不允许生成“图/表”前缀、章节号、顺序号或分隔符。前缀和编号由确定性规则依据原格式快照计算，仅用于结构化报告展示；未来即使提供写回，也必须根据写回时文档状态重新校验，不能复用旧编号。题注正文最多八十个 Unicode 字符，不得包含 Markdown、换行或解释性前后缀，并必须携带证据状态、简短证据说明、置信度及无法确认的信息。响应含有模型自编题注编号、不受证据支持的具体事实或被禁止的格式字符时，拒绝整条建议，不通过删除字符串等猜测方式修复。该分离避免模型编号与 Word 题注域、章节编号或文档当前顺序发生冲突；所有建议仍为只读内容，不表示原文已有题注。
