# 模型直连使用版本化任务系统提示词

AI-WPS 为八类模型任务各维护一份经过审阅的 Markdown 任务系统提示词。模型直连通过 `system` 消息加载对应文件，并把现有完整任务提示词作为 `user` 消息；工作流平台仍由平台内部配置相同版本的任务系统提示词，Adapter 不向平台 query 重复注入。

任务系统提示词是随版本发布的运行资产，模型配置不得编辑。交付包同时提供这八份 Markdown，既作为模型直连的唯一运行来源，也供工作流平台运维人员手工复制和核对；这是因为现有平台应用 API 无法让 Adapter 自动读取或更新内部 System Prompt。智能仿写在本版本补齐独立模板。
