# 将段内混合字符格式抽取为自适应区段

WPS 段落或单元格 Range 在内部混用字体、字号、粗体等属性时通常只返回混合或未定义值，无法定位具体偏差；逐字符访问又会在六万至十二万字文档中产生不可接受的大量 WPS 对象调用。决定先读取完整 Range 的字符格式，属性一致时形成单一区段，属性混合时递归二分 Range，直到得到同质区段，并合并相邻且属性相同的区段。快照只记录块内相对字符范围和格式事实，不为每个区段重复保存全文文本。

极端碎片化段落超过区段安全上限，或麒麟 WPS 不能可靠复制、切分和读取 Range 时，该对象必须标记“字符格式数据不足”，不得保留前若干区段后判定合规，也不得退回段落平均格式。目标 WPS 真机验收覆盖中英文、数字、粗斜体、上下标、不同字体字号混排及表格单元格。该算法显著减少常规文档对象访问，但其 WPS 12.1.2 行为仍需真机验证。
