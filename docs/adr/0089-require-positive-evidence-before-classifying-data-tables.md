# 数据表分类必须具有正向结构证据

授权规则的表格语义框架区分 `data`、`code_sample`、`callout`、`layout` 和 `unknown`，但其转换场景会把大多数多可视单元格、非代码且非公式布局的表格直接判为 `data` 并赋予 `1.0` 置信度。决定格式审查复用分类框架及公式布局、代码载荷、单单元格说明框等可验证分支，但只有存在明确表头、重复行结构、稳定列语义或多行记录等正向证据时才确定为数据表；其余多单元格表格为未知，不执行数据表专属格式或缺表题规则，只执行与语义类型无关的通用规则并披露数据不足。首版不把表格类型加入模型操作白名单。该适配降低了部分数据表的自动覆盖率，但避免将转换工具的激进归一化假设升级为只读合规结论。
