# 将格式审查模型限制为经过验证的语义操作

决定格式审查模型只接收确定性规则无法可靠处理的模糊格式候选，并且首版只允许返回段落角色分类、题注关联、图题建议和表题建议四类版本化操作。操作必须绑定格式审查快照指纹和稳定块标识，通过 JSON Schema、候选范围、允许目标及冲突校验；模型不得返回格式合规结论、修改模板要求或覆盖确定性证据。角色或题注关联置信度达到 `0.85` 且不与确定性证据冲突时，才可用于选择后续确定性规则；未达到门槛的对象保持“需要确认的格式角色”，不得默认按正文处理。

模型生成的图题或表题无论置信度多高都只作为建议题注展示，不能记为原文已有内容、自动消除缺题问题或直接写回 Word。模型未配置、超时、返回无效或部分失败时，确定性报告仍正常完成，缺题问题继续存在，只缺少建议文案。该边界降低模型覆盖率，但防止随机输出成为格式标准或隐式修改文档。
