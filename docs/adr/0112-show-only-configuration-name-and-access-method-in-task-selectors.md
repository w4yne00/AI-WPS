# 任务页模型下拉只显示配置名称和接入方式

决定 Word、Excel 和 PPT 所有任务页的模型配置下拉项统一显示为 `配置名称 · 接入方式`，接入方式只使用“工作流平台”或“模型直连”。模型直连的模型标识不再出现在任务页下拉项中，API 地址、Key 状态、备注、完整度和默认激活勾选也不得拼入选项文字；选中状态由原生 `select` 状态表达，切换反馈在下拉外显示。模型标识仍是模型直连配置的必填运行参数，并继续在设置页配置详情和编辑子页显示，本决定不删除字段、不改变 Adapter API、配置完整度或任务执行基线。三个宿主必须复用同一标签格式化规则并增加下拉显示契约测试，避免 Word 与 Excel/PPT 再次漂移。
