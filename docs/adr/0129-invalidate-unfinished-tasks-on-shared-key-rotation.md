# 共享直连密钥轮换使未结束任务失效

直连服务的 API Key 被替换或清除后，所有引用旧 Key 的排队、运行和可恢复任务都进入不可恢复失败并要求用户重新提交；新任务使用新 Key，Adapter 不保留旧 Key 版本，也不让旧任务静默改用新认证。该选择会浪费已经完成的部分处理并打断长任务，但避免为任务连续性复制或延长保存敏感凭据，也保证一次任务不会跨认证身份继续执行。

轮换事件记录发生轮换时的服务 revision，并使相同服务、相同旧 Key 指纹且任务 revision 小于或等于该 revision 的未结束任务失效；同一 Key 指纹在更高 revision 上创建的新任务不受影响。已完成任务及历史记录只读保留。
