# 候选仅能恢复时不得自动切换

当当前安装已经不可用、候选 Adapter 能够存活但因原数据异常只能进入恢复模式时，首次安装命令仍不得自动切换。安装器保留当前安装和候选隔离目录，输出脱敏故障摘要、备份状态和恢复命令。只有当前版本同样不就绪、原数据备份校验通过、候选 `/health/live` 返回 200 且 `/health.status` 为 `recovery` 时，用户才可以显式执行 `--activate-recovery`。激活后只开放诊断、备份和恢复能力，受影响任务保持禁用，安装结果必须标记为“已激活恢复模式”，不能标记为升级成功或已验收恢复构建。该方案增加一次人工操作，却避免把数据异常候选自动提升为正式版本，同时为旧版本已经死亡的现场保留可访问恢复入口。
