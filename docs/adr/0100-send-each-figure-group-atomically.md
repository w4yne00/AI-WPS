# 将一个图对象组作为原子视觉语义批次

决定首版每次图像语义调用只处理一个可关联图对象组，并在同一次请求中完整发送组内图片；单组最多四张图片，一个图对象组占用一次格式语义调用预算。组内每张图片都必须通过格式图片单体门禁，当前模型配置的视觉能力验证也必须确认支持本组图片数量。任一图片导出或校验失败、组内超过四张、传输协议或后台模型只能接收更少图片时，不得选择部分图片后为整组生成图题，整组改用 Alt Text 和邻近文字形成 `text_evidence_only`，文字证据不足则为 `not_assessable`。该决定防止模型只观察部分子图却输出看似完整的整体题注，代价是复杂拼图和能力较弱的模型更容易降级；首版不拆分图对象组，也不合并不同图对象组共享一次调用。
