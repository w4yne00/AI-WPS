# 使用 Adapter 受控槽位承接 WPS 图片导出

决定首版不允许 WPS 前端或调用方为格式审查图片提交任意本地文件路径。Adapter 在格式快照会话下为每个待导出的格式图片资产创建随机资产标识和受控临时 PNG 槽位，槽位目录仅允许当前安装主体访问；WPS 只能向 Adapter 指定的槽位调用 `SaveAsPicture`，完成后按资产标识提交。Adapter 接收时必须将路径规范化并确认仍位于本会话槽位目录，使用 `lstat` 拒绝符号链接和非普通文件，校验预期属主、PNG 文件签名、尺寸、文件大小和 SHA-256 后才形成格式图片资产。路径和文件名不得包含文档名、原图片名或正文信息，也不得进入业务日志、诊断包和审查报告。提交失败、任务完成、失败、取消或会话超时后立即删除槽位及其临时 PNG。该设计阻断通过图片上传接口读取或发送目标机任意文件的路径注入风险，同时要求安装与运行过程继续满足安装主体一致性。
