# 当前样式只作为角色证据而非角色真相

决定格式审查不得根据当前样式名称或格式属性直接确定内容角色，否则正文误用标题样式会形成“样式证明角色、角色又证明样式合规”的循环。目录域、题注域、编号定义和对象包含关系等明确结构事实可以直接确认相应角色；样式名称、OutlineLevel、编号外观、文本模式、文档位置和相邻关系作为来源可区分的证据，只有明确结构事实或至少两类相互独立的强证据一致时才确定性确认。样式证据单独存在或与其它证据冲突时进入模糊格式候选，模型只能从规则生成的有限候选组合中选择；仍未达到门槛时保持需要确认。报告必须区分角色已确认但样式不符、当前样式与角色证据冲突和角色仍无法确认。该原则会增加人工核对项，但使格式合规判断不依赖被审查对象自身声明的正确性。
