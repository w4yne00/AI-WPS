# Python 依赖按发布代际隔离

当前安装器优先向系统或用户 `site-packages` 安装离线依赖，即使候选构建最终回退，目标 Python 环境也已经发生不可追踪的全局变化，并可能影响旧 Adapter。决定每个发布代际拥有独立的 Python 依赖目录，使用交付包内经过校验的离线 Wheel 和锁定清单安装；候选完整导入、隔离预检和正式启动必须使用同一私有依赖目录，并设置 `PYTHONNOUSERSITE=1`，禁止加载用户 `site-packages`。安装不得修改系统或用户 Python 环境；目标机缺少 `venv` 时使用版本私有目标目录，不得退回全局安装；回退发布代际时同时回退其依赖目录。该方案重复占用部分磁盘并增加启动环境配置，但保证预检与正式运行一致，使依赖也进入可验证、可回退的发布边界。
