# Word 格式审查使用独立增量快照协议

现有格式审查通过单个 `POST /word/format-review` 请求发送最多八十段和一万二千字符，既不能证明全篇覆盖，也会在扩大同步 WPS 对象扫描后重新引入任务窗格阻塞。决定新增独立的 `/word/format-review/snapshots/...` 与 `/word/format-review/jobs/...` 协议：WPS 按文档顺序分批抽取格式语义块，每批上传后主动让出事件循环；Adapter 校验秘密上传令牌、连续批次、对象范围、累计上限、哈希和覆盖清单，提交快照后在后台执行确定性审计，仅将模糊候选交给模型。该协议复用全篇文档审查已有的安全暂存、过期清理和后台任务基础设施，但使用独立的格式快照模式和结果契约。

日常六万字和极端十二万字使用同一协议，不按段落数或字符数静默截断。模型未配置或失败不阻断确定性结果。旧 `POST /word/format-review` 保留一个版本作为兼容入口，新任务窗格统一使用增量快照协议。新增协议和状态管理提高实现复杂度，但避免巨型单请求、前端双份全文内存和长时间无响应，并使覆盖完整性可验证。
