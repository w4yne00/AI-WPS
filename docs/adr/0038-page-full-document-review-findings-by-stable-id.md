# Word 全篇审查结果按稳定问题标识分页读取

Word 全篇审查任务的终态查询只返回覆盖状态、枚举状态、问题数量和分类统计等摘要；最终问题使用稳定 `issueId`，通过独立接口默认每页 20 项读取，处理状态也以 `issueId` 为键。完整审查记录由 Adapter 根据持久化终态结果生成，不要求 WPS 任务窗格预先加载和渲染全部问题。

现有文档审查把全部问题放入一个终态响应并按数组下标保存状态，无法稳定支撑长文档的大结果集：去重、排序或分页会改变下标，大段 Markdown 也会增加窄任务窗格渲染和重复轮询成本。分页增加了结果存储、游标和清理接口，但使终态轮询保持轻量，并为筛选、排序和按需查看提供稳定边界。
