# 图片外发必须获得配置级显式授权

决定首版所有模型配置的图片输入模式默认为 `disabled`。管理员启用 OpenAI 兼容 `image_url` 或 Dify 文件上传时，必须显式确认允许将符合条件的文档图片发送至当前模型服务；界面显示目标服务主机、传输模式以及远端留存受目标服务策略控制的提示，不显示 API Key。授权绑定模型配置修订、服务主机、图片输入模式和模型标识，任一项变化后授权和视觉能力验证同时失效，必须重新确认和验证。任务发起页显示图片外发已启用，并允许用户仅对本次任务关闭图片增强，不要求每次重复授权。结构化报告记录候选数、实际上传数、目标主机、模式和证据状态，不记录图片内容、本地路径或请求正文。AI-WPS 只能声明本机临时 PNG 已按批次清理；除非目标服务提供并成功执行可验证的删除契约，否则不得声称远端图片已经删除或未被留存。
