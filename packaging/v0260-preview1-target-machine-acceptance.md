## Excel“智能填写”目标机验收

| 项目 | 预期结果 | 现场证据（脱敏） |
| --- | --- | --- |
| Ribbon 入口 | Excel 只显示“智能分析”“公式助手”“智能填写”和“设置” |  |
| 来源范围 | 同一工作表含一行表头和至少一行可见数据的连续矩形，最多 500 个数据行；点击“生成预览”才冻结；非连续、仅表头、隐藏、合并、超限拒绝 |  |
| 三阶段流程 | 先选取含表头来源并填写意图，生成无地址预览，再选择同表连续单列目标并写入；不出现来源或目标捕获按钮 |  |
| 目标范围 | 点击写入时重新读取当前选区；目标与来源同表、不重叠、连续单列，单元格数量等于全部预览项数量 |  |
| 预览协议 | 结果严格按 `excel.smart_fill.v2` 展示，可逐项编辑、排除和重试 |  |
| 写入门禁 | 写回前重新校验工作簿/工作表/来源快照及目标原值；普通文本/数值需要二次确认；`= + - @` 前缀按文本保护；公式、合并、保护单元格始终拒绝 |  |
| 写回边界 | 仅写入用户选中的完成项，不提供撤销；写回动作不新增或修改历史；生成成功结果已只读归档；失败时执行写入失败补偿并报告准确地址 |  |
| 任务恢复 | 慢模型持续轮询；运行中取消显示部分预览，任务总时限 60 分钟，结果仅进程内保留 |  |
| 数据边界 | 模型请求不含地址、工作簿标识、公式表达式、公式计算结果、隐藏值和未授权工作表内容 |  |

## 证据位置与失败回退

- 安装候选：以本记录“归档文件”和包外 `.sha256` 为唯一候选身份，验收前复核哈希。
- 自动化证据：构建输出应包含 Python 全量回归、三宿主 Node、Vite/Vitest、JavaScript 与 Shell 语法、Python 3.8 兼容扫描、白名单和最终交付审计结果。
- 现场证据：由验收人员填写受控证据编号；不得把 API Key、用户正文、模型原始响应或敏感绝对路径写入本记录。
- 失败回退：任一必测项失败时停止分发并记录为 `failed`；保留当前已安装版本及候选归档，不以失败候选覆盖既有状态。安装失败按事务回退结果核验 `current` 指针、配置、API Key、任务映射和备份；智能填写补偿失败时按提示地址人工核对单元格。

## 验收结论规则

- `manual-pending`：尚未完成全部目标机和安装边界验证。
- `passed`：所有必测项目均有现场证据，且没有失败、阻塞或未验证项。
- `failed`：发现旧目录被修改、运行数据被自动导入/删除、Preview 身份泄漏，或交付闭包不完整。

自动化构建与静态审计通过只能记录 `candidate`，不能将本记录写成 `passed` 或 `target-accepted`。
