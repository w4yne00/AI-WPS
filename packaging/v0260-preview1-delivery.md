# AI-WPS v0.26.0-preview.1

这是 AI-WPS `v0.26.0-preview.1` 离线安装候选，覆盖 Word、Excel、PPT 的 13 类模型任务及 PPT 模板整套生成。包内只保留安装、运行、配置、诊断和验收所需文件。

[English](./README.md) | [中文](./README-ZH.md)

## 交付身份

- 产品版本：`v0.26.0-preview.1`
- 产品通道：`preview`
- 归档命名：`ai-wps-delivery-<YYYYMMDD>-<SOURCE_COMMIT>-v0260-preview1.tar.gz`
- 默认安装根：`$TARGET_HOME/ai-wps`
- 管理路径边界：安装根、共享状态、备份、运行变量及 WPS 插件目录必须位于 `$TARGET_HOME` 下，且不接受符号链接路径组件
- 安装入口：`installer/install_ai_wps.sh`
- 冒烟入口：`scripts/ai_wps_smoke_test.sh`
- 交付状态：自动化门禁只能记录 `candidate`
- 目标机状态：首次 Preview 验收前保持 `manual-pending`
- 自动化状态：构建、回归、语法、兼容性和交付审计全部通过后，仅登记为 `candidate`
- 目标机人工验收：绑定 Issue #154，当前为 `manual-pending`，不宣称已在真实 WPS 或真实模型环境通过验收
- 插件缓存身份：每个候选使用 `0.26.0-preview.1-<SOURCE_COMMIT_PREFIX>` 作为任务窗格、辅助脚本和 Ribbon 的静态资源缓存键；同版本不同提交不得复用缓存 URL

`release-manifest.json`、`release-allowlist.json` 和 `release-file-hashes.json` 是同一候选的身份、白名单和完整性边界。发布脚本只从显式白名单组装文件，不把仓库测试、缓存、历史归档或运行数据带入交付包。

## 从历史安装进入 Preview

覆盖升级现有 `$TARGET_HOME/ai-wps` 时，安装器要求先关闭 WPS，随后自行停止正在运行的旧 Adapter，隔离预检新候选，事务式替换 Adapter 代际、Word/Excel/PPT 插件目录和发布清单，再启动并健康检查新 Adapter。配置、API Key、运行数据与备份保持在共享状态目录；切换或启动失败时恢复旧代际并重新启动旧 Adapter。

首次安装仍会只读检测 `$TARGET_HOME/ai-wps-phase1`。若历史 Adapter 占用目标端口，安装器先停止旧进程，再覆盖公共 WPS 插件目录并启动位于 `$TARGET_HOME/ai-wps` 的新 Adapter；旧 Phase1 目录中的配置、API Key、规范库、备份和运行数据不自动导入、覆盖或删除，由管理员保留并按现场方案重新配置。这样既保证旧进程不会与新进程争用端口，也不把未经验证的历史状态静默带入新候选。

Preview 的默认安装根、脚本名、release ID 和成功标记均使用 `ai-wps` / `AI-WPS` 中性身份。现有 Phase1 交付路径继续保留在源码仓库中，供已部署环境维护和历史追溯；本包不执行破坏性全库重命名。

## 安装与验证

```bash
bash installer/install_ai_wps.sh
bash scripts/ai_wps_smoke_test.sh
```

安装成功后，目标用户的桌面会出现“重启 AI-WPS 后台服务”快捷方式。它始终通过当前安装版本重启并检查后台，保留安装时的 Python 解释器、端口、状态与备份目录及自定义系统服务设置；重复安装会更新同一个快捷方式。若系统未能自动标记为可信，首次使用时请右键选择“允许启动”或“允许执行”。安装器只检查 WPS 是否已退出，请先自行保存并关闭文档。

安装器复用经过验证的私有 Python 运行时、候选预检、事务式发布和生命周期组件。Preview 首次安装以空状态初始化；从 `v0.26.0-preview.1` 起的后续兼容升级必须保留配置和运行数据，并由单独的兼容升级合同约束。

自动化构建会执行白名单组装、版本和引用闭包审计、敏感值扫描、文件 SHA-256 清单、Python 3.8 兼容性检查、正式插件契约测试及最终归档生命周期门禁。自动化通过不等于麒麟 V10/WPS 目标机已经验收。

## Scope

本交付包在保持既有 Word、Excel 和 PPT 任务行为的基础上，将 13 类模型任务及本轮体验调整纳入同一白名单交付闭包：

- **工作流平台继续按功能独立配置**：Word 5 类、Excel 4 类、PPT 4 类各自保存工作流地址、API Key 与编排参数，调用 `/chat-messages`。
- **共享直连服务**：同一 Adapter 运行环境只录入一次服务地址和 API Key；各任务选择该服务并覆盖任务模型和参数，调用 `/chat/completions`。成功结果进入只读历史，失败和取消不归档。
- **智能填写严格边界**：生成阶段仅接受同一工作表含表头的连续矩形来源（最多 500 个数据行）和必填填写意图；模型请求不含目标地址、工作簿标识、公式或隐藏数据，模型结果严格遵循 `excel.smart_fill.v2` Schema。任务窗格不再绑定写入目标。
- **智能填写只读流程**：正式路径固定为“来源范围与填写意图 → Markdown 结果预览 → 复制并人工粘贴”；不提供结果编辑、勾选、逐项重试、目标区域绑定或工作簿写回入口。
- **长任务生命周期**：复用共享长任务协调器，支持 10 秒短轮询、排队取消、运行中协作取消、部分预览和 60 分钟总时限，任务结果仅进程内保留 2 小时。
- **复制与人工粘贴**：结果卡按来源行展示安全 Markdown；“复制结果”输出两列制表符文本，值中的制表符和换行转为空格。复制动作不修改工作簿，粘贴位置和最终内容由用户自行确认。
- **Word 格式审查结果**：自动目录和满足多证据条件的手工目录进入目录审查豁免区；疑似目录抑制正文格式误报并将覆盖状态降为 `partial`。格式问题按稳定位置分组，筛选进入锚定面板，导出进入更多菜单。
- **三宿主紧凑配置入口**：Word 5 类、Excel 4 类、PPT 4 类任务页统一显示“配置名称 · 接入方式”的单行入口，保留即时激活、忙碌门禁、失败回滚、键盘导航和完整设置页。
- **按需编写**：上传 DOCX，或由 WPS 原生接口将 DOC 临时副本转换后读取；完整文字、表格与原图一同输入支持图片的直连模型，按自由提示词生成段落或整篇，并复用智能编写的写作规范。界面保留参考文档、写作要求和结果预览，出处默认折叠，只允许主动在光标处插入。超文字容量明确拒绝，不截断或删图；图像 Token 无可靠估计时明确提示，沿用每张原图 5 MiB 通道限制。未读取对象会阻止生成，真实 DOC 转换、插入与多模态识图仍须现场验收。
- **资料台账**：按上传资料和提取要求生成台账，预览确认后仅写入工作表中确认的空白区域；再次生成使用新任务，失败或中断的写入需先核对。
- **PPT 资料大纲与模板生成**：资料大纲支持流式接收和取消，完成校验后展示；确认大纲后可生成模板正文页或整套内容，经预览确认后追加到当前演示文稿。任务和写入确认按文档会话隔离，已有页面保持不变。文档、大纲或预览变化后须重新确认；部分写入异常时先核查恢复，再继续追加。
- **手填模型与自动验证**：三宿主可添加、删除手填默认模型和任务模型。Word 智能编写、智能仿写选择目录模型时先验证流式能力，手填模型先保存再后台验证；格式审查分别自动验证语义和视觉能力，直连图片默认使用 `openai_image_url`。验证使用合成内容，可能产生模型费用；失败不会伪造已验证状态。
- **设置页细节统一**：三宿主“接入选择”不显示叹号，标题与选择框保持 8px 间距；直连与工作流“新建”使用同一紧凑按钮；直连空状态居中，工作流卡片不重复显示当前配置摘要。
- **候选级缓存隔离**：静态资源 URL 和前端诊断显示源码提交标识，覆盖安装同一 Preview 版本的新候选时不会继续复用旧任务窗格脚本；候选审计校验该身份。
- **窄窗与可访问性**：候选自动化覆盖 320×700、420×900、按钮几何、键盘焦点、可访问名称和 `prefers-reduced-motion`；真实 WPS 交互仍由 Issue #154 现场验证。
- **交互文本流式与只读预览**：Word 智能编写与智能仿写直连模型支持可恢复的增量文本预览；`AI_WPS_ENABLE_DIRECT_STREAMING` 默认开启，当前服务修订和模型能力为 `validated` 时启用增量预览与运行中取消。显式设为 `0` 可立即回退阻塞调用与 3 秒短轮询；增量预览保持不可写回、零历史归档。
- **跨重启共享状态**：当前安装代际在未显式设置路径变量时自动绑定 `$TARGET_HOME/ai-wps/state`、`backups` 和 `var`。模型配置、工作流配置、API Key 和规范库不会因手工重启、systemd 重启或 release 切换而回退到程序目录内的空状态。
- **三宿主毫秒性能诊断**：长任务轮询接口与终态诊断公开单调毫秒级指标（`elapsedMs`、`phaseElapsedMs`、`phaseDurationsMs`、`queueWaitMs`、`metrics`）及真实 `providerOutcome`；阻塞调用首包时间严格为 `null`；严格零用户正文、零提示词与零凭据泄露。
- **平滑降级与回滚合同**：增量事件接口 404 或连续异常时，正式任务窗格自动降级至 3 秒短轮询，不清除配置、不破坏文档会话、不清理历史；新增能力字段向后兼容，加载旧配置默认赋予 `not_checked`，不要求破坏性配置迁移。
- **一次性安装断代**：默认安装根为 `$TARGET_HOME/ai-wps`，只读检测历史 `$TARGET_HOME/ai-wps-phase1` 并提示人工重装与重新配置，绝不自动迁移、覆盖或删除历史数据。
- **验收状态边界**：自动化门禁通过后仅记录 `candidate`，目标机验收保持 `manual-pending`（绑定 Issue #154），不提前宣称通过真实 WPS 或现场工作流验收。
