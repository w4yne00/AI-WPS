# v0.25.0 最终白名单候选交付包

最终包以已验收的 v0.24.0 候选包为升级基线，合并确定性优先格式审查、受限语义参考 DSL、三宿主插件、Adapter、规则包、目标 Python 3.8 依赖和运维材料。构建只从 `delivery-sources-v0250.json` 的显式文件清单组装。

包内状态固定为 `candidate`。自动化门禁验证升级、导入、Uvicorn、公开健康与配置协议、插件契约、规则包、参考 DSL、文件哈希、引用闭包、敏感值和生命周期故障；它不替代麒麟 V10、目标 WPS 和 `cloud` 用户现场验收。

图片语义随包休眠交付。新安装和升级后的视觉总开关为 `false`，关闭时不分配图片槽位、不调用 `SaveAsPicture`、不生成 PNG、不上传像素；确定性图片盘点、缺图题和题注位置规则继续运行。
