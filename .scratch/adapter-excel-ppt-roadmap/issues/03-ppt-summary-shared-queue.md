# 03 — PPT 智能总结迁移到共享队列

**What to build:** 让 PPT 当前页总结和文档总结复用共享任务协调器。文档任务在提交时取得本地暂存文件所有权，排队期间不会因一次性令牌过期而丢失，只有获得执行槽位后才上传模型后台。

**Blocked by:** 01 — 文档审查接入共享任务协调器

**Status:** ready-for-agent

- [ ] 当前页总结和文档总结使用同一共享协调器，并保持现有结果、复制和只读行为。
- [ ] 文档任务在队列提交时验证并消费一次性令牌，文件转为任务独占资源。
- [ ] 排队期间不上传 Dify；获得执行槽位后，上传和消息请求使用同一认证快照。
- [ ] 重复 `clientJobId` 不重复消费令牌、上传文件或调用模型。
- [ ] 排队取消、完成、失败和 Adapter 退出路径均清理任务文件。
- [ ] 前端显示排队、准备、上传、模型处理和解析阶段，不显示估算百分比。
- [ ] 当前页标题、副标题、文档页数选项、长任务恢复及 FastAPI/standalone 契约无回归。
