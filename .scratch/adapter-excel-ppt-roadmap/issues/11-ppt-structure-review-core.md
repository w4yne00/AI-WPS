# 11 — 交付 PPT 结构审查最小闭环

**What to build:** 为 PPT 增加独立“结构审查”入口。用户对不超过 60 页且具有标题的演示文稿发起审查后，获得整体主线、推断章节、分级结构问题、逐页建议和推荐目录；幻灯片不会被自动修改。

**Blocked by:** 10 — 交付并验收 v0.21.0-alpha

**Status:** ready-for-agent

- [ ] PPT Ribbon 新增“结构审查”，且只在 PPT 宿主显示。
- [ ] 新任务类型使用独立工作流档案、独立 API Key 和 PPT 设置选项卡。
- [ ] 提取请求范围内的页码、主标题和可选副标题，主标题与副标题保持分离。
- [ ] 超过 60 页的整套请求先明确拒绝，不静默截断或自动拆成多次模型调用。
- [ ] 本地检查空标题、完全重复标题、过长标题和明显编号跳号。
- [ ] 单次模型调用分析主线、章节、顺序、重复和内容缺口，并与本地问题合并去重。
- [ ] 结果包含高优先级问题、一般建议、带页码的调整意见和推荐目录，不显示数值总分。
- [ ] 支持复制审查结论和推荐目录，绝不创建、删除、重排或修改幻灯片。
