# 09 — 补齐公式解释排错与本地检查

**What to build:** 让公式助手既能解释选区中的已有公式，也能在复制前指出基础语法、引用和兼容性风险。用户获得可理解的分段说明和有依据的修正建议，但界面不把静态检查包装成计算正确性证明。

**Blocked by:** 08 — 交付 Excel 公式生成最小闭环

**Status:** ready-for-agent

- [ ] 任务窗格使用“生成公式 / 解释排错”分段控件，模式由用户明确选择。
- [ ] 解释模式读取选区已有公式并返回原公式、组件说明、引用范围、发现问题和有依据的修正公式。
- [ ] 结果支持一个主公式和一个仅在确有差异时折叠显示的备选公式。
- [ ] 本地非执行检查覆盖 `=` 前缀、括号、引号、长度、外部工作簿、URL/网络函数、明显越界引用和兼容清单。
- [ ] 检查只显示“基础检查通过”或具体风险，不声称公式或计算结果正确。
- [ ] 不通过隐藏单元格、临时工作表或其他写入方式试算公式。
- [ ] 模型输出解析失败时保留可复制的原始最终结果和中文诊断。
- [ ] 生成、解释、复制、键盘操作和窄窗布局均有用户可见契约测试。
