# 08 — 交付 Excel 公式生成最小闭环

**What to build:** 为 Excel 增加独立“公式助手”入口和公式生成模式。用户框选相关表格、描述计算需求后，获得一个清晰的推荐公式、建议位置、逻辑解释和复制动作；工作簿不会被自动修改。

**Blocked by:** 07 — 交付并验收 v0.20.1-alpha

**Status:** ready-for-agent

- [ ] Excel Ribbon 新增“公式助手”，且只在 Excel 宿主显示。
- [ ] 新任务类型使用独立工作流档案、独立 API Key 和 Excel 设置选项卡。
- [ ] 生成模式要求用户明确选择范围并填写计算需求，不回退读取 UsedRange。
- [ ] 提取地址、表头、单元格文本、有限类型和现有公式，最多 30 行 × 20 列，并明确显示截断状态。
- [ ] 任务使用共享队列、提交快照、阶段反馈、轮询恢复和排队取消能力。
- [ ] 结果显示一个主公式、建议位置、逻辑解释、引用假设、兼容提示和复制动作。
- [ ] 不设置单元格 Formula、不填充范围、不创建工作表、不改变计算模式或撤销记录。
- [ ] think 内容过滤、Dify 两种输入模式、FastAPI/standalone 和现有智能分析均无回归。
