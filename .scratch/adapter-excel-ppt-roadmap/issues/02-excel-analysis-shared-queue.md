# 02 — Excel 智能分析迁移到共享队列

**What to build:** 让现有 Excel 智能分析复用共享任务协调器。用户仍获得相同的数据概览、关键发现、风险异常、建议动作和汇报段落，同时能够看到排队位置、真实阶段和耗时，并在短暂断连或重开任务窗格后继续查询同一任务。

**Blocked by:** 01 — 文档审查接入共享任务协调器

**Status:** ready-for-agent

- [ ] 智能分析使用共享协调器，不再为每次请求独立创建无界后台线程。
- [ ] 现有智能分析提交、轮询、结果、复制、选区优先和 UsedRange 兜底行为保持不变。
- [ ] 重复 `clientJobId` 只触发一次模型请求，并返回同一个任务状态。
- [ ] Excel 任务参与全局并发和 FIFO 排队，运行中记录绝不因容量被移除。
- [ ] 前端正确显示 queued、running、completed、failed、cancelled 和中文容量错误。
- [ ] 短暂状态查询失败不清空任务号或重复提交。
- [ ] FastAPI 与 standalone 契约和现有回归测试通过。
