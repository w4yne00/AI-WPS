# 04 — 完成三宿主队列容量与高级诊断闭环

**What to build:** 让 Word、Excel 和 PPT 的长任务真正共享一个全局容量边界，并为用户和运维人员提供准确、脱敏的当前任务和高级诊断反馈。任何宿主都不能绕过并发、排队、终态清理或认证释放规则。

**Blocked by:** 02 — Excel 智能分析迁移到共享队列；03 — PPT 智能总结迁移到共享队列

**Status:** ready-for-agent

- [ ] 跨宿主验证默认全局 2 个运行任务和 8 个排队位置，而不是每个宿主分别计算容量。
- [ ] 跨宿主 FIFO、公平排队、满队列中文拒绝和排队取消可通过外部契约验证。
- [ ] queued/running 永不因终态容量清理而丢失；终态执行 2 小时和 50 条双重边界。
- [ ] 任务页只展示当前任务的排队位置、阶段、耗时和可取消状态。
- [ ] 折叠高级诊断展示有效配置、运行数、排队数、近期终态耗时、取消/拒绝/超时计数和脱敏错误码。
- [ ] 诊断不包含 API Key、用户全文、文档正文、公式正文或完整上传文件名。
- [ ] Adapter 重启后，前端保存但服务端不存在的任务显示明确中断提示和重新提交操作。
- [ ] 不新增统一任务中心、长期任务历史或新的持久化凭据。
