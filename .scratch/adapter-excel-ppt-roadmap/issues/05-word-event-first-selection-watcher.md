# 05 — Word 选区监听改为事件优先

**What to build:** 降低 Word 任务窗格空闲时对 WPS 对象的周期性访问。选区变化优先由宿主事件驱动；事件不可用或漏报时，页面可见状态下仍通过低频轮询恢复，用户看到的识别范围保持及时和准确。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 支持时优先使用 Word 选区变化事件更新范围摘要。
- [ ] 事件注册失败、事件不可用或长时间无事件时自动启用约 2 秒低频兜底轮询。
- [ ] 页面隐藏、进入设置或模型任务运行期间暂停无意义的选区读取。
- [ ] 页面重新可见或返回任务页时立即刷新一次并恢复正确监听模式。
- [ ] 只有范围摘要变化时更新 DOM 和可访问状态文本。
- [ ] 智能编写、智能仿写、文档审查和格式审查现有选区抽取与写回边界不变。
- [ ] 模拟 WPS 对象测试与麒麟 V10 事件/兜底验收步骤齐全。
