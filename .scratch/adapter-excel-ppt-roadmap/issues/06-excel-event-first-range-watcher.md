# 06 — Excel 选区监听改为事件优先

**What to build:** 让 Excel 任务窗格复用已验证的事件优先、低频兜底和可见性控制模式。用户切换选区时范围摘要及时更新，而隐藏任务窗格和任务运行期间不再持续检查工作表对象。

**Blocked by:** 05 — Word 选区监听改为事件优先

**Status:** ready-for-agent

- [ ] 支持时优先使用 Excel 工作表选区变化事件更新范围摘要。
- [ ] 事件不可用时使用约 2 秒可见页面轮询兜底，并能从漏报状态恢复。
- [ ] 页面隐藏、进入设置或模型任务运行期间暂停范围读取。
- [ ] 只在选区类型、工作表、地址或行列摘要变化时更新界面。
- [ ] 智能分析的实际提交仍在用户点击后读取数据，不使用过期的状态摘要代替真实选区。
- [ ] 现有选区优先、UsedRange 兜底和智能分析数据预算保持不变。
- [ ] 模拟对象、浏览器窄窗和麒麟 V10 事件兼容验收覆盖完整。
